# 2.4.0 升级与恢复

上一正式组合版为 2.3.0。本版只更新独立 Research 到 2.2.0，其余11个模块固定版本不变。具体能力、适用条件、引用与许可见 Research README 和本版模块升级说明。

先按需 fetch research，再运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅管理文件和用户修改后加 `--apply`。保留返回的 transaction，回退使用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply`。用户编辑的变化文件拒绝覆盖，无关模块编辑与用户数据保留。

报告、原型、素材及运行配置由接收方在包外维护，包升级不接管它们。持续试玩浮层与图文阅读在生成的报告内工作；外部编辑服务仅在已配置且有本次材料和费用授权时使用，未配置时继续普通研究与渲染。安装不启动研究、代理、采集、服务或付费模型。

旧tag、版本化清单及恢复记录保留。独立模块使用者对照模块本版说明审阅差异；历史组合沿既有升级链抵达 2.3.0，不能跳过前版合同。
