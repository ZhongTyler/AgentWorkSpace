# 2.7.0 升级与恢复

上一正式版本为 2.6.0。本次更新 Knowledge 2.1.1、FromDemoToSpec 2.2.0、GameProject 2.2.0（Godot 模板 0.2.26）和 Brainstorm 2.1.0，其余8个模块固定身份保持。每个模块可独立使用，AWS/meta 仍为可选协作层。

先按需 fetch 这四个模块，再运行 `python scripts/workspace.py upgrade --target <workspace>` 查看差异，确认后加 `--apply`。受影响文件有用户编辑时拒绝覆盖；宿主规则、私人资料、项目及其他模块的编辑保持。保留 transaction，通过 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply` 回退。

GameProject 更新模板包，已有游戏是独立副本，不会自动迁移、覆写图册、重建引擎或改写 Git 历史。比较新旧模板后只吸收需要的变化，历史媒体恢复使用接收方已有的档案。FromDemoToSpec 的 `check-state` 保持兼容，准备扩展特定范围时才补 `next_expansion`；新增校验只核对申报的证据与阻断关系，不替代真实试玩、语义审阅或用户认可。

Knowledge 不携带私人正文/回执；Brainstorm 对照案例不是已采用决定。安装和升级不会启动服务、付费调用、下载模型或部署个人网站。独立 checkout 保留旧版和用户数据，按模块各版说明切换调用或恢复；不可用的可选模块不阻断其他独立工作。
