# 2.4.1 升级与恢复

上一正式组合版为 2.4.0。本版只更新独立 Skills 到 2.2.2，其余11个模块固定版本不变。42项方法的中文名称/说明及来源映射使用网站实际润色和语义复核后回交的同一最终稿。调用ID、路径、代码及上游原件许可保持；外部方法按实际来源标注，不归为作者原创。具体字段与来源见 Skills README 和本版模块说明。

先按需 fetch skills，再运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅管理文件和用户修改后加 `--apply`。保留返回的 transaction，回退使用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply`。用户编辑的变化文件拒绝覆盖，无关模块编辑与用户数据保留。

包更新与客户端 Skill 更新分别执行。新版本包内 `python scripts/skills.py upgrade --target <host> --platform codex --apply` 更新已选方法，CodeBuddy 使用 codebuddy 平台参数，各自保留 transaction 并用同一脚本 rollback 恢复。本版不新增方法；中文展示不改变调用ID，运行和外发仍沿宿主实际能力及授权。

旧tag、版本化清单及恢复记录保留。独立模块使用者对照模块本版说明审阅差异；历史组合沿既有升级链抵达 2.4.0，不能跳过前版合同。
