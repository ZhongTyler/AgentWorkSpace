# 2.10.0 升级与恢复

从2.9.1更新 Meta2.0.0 至2.1.0：新增 WORKFLOW_CONTRACT.md，COMMAND_MANUAL.md 改为用户目的指南并保留旧五个章节锚点；Review补事实/解释分离、owner路由、有限试用、采用/撤回与后续消费回看。记忆与画像模板保持空白，16篇why及搭建说明保留在独立Meta仓。其余11模块版本、提交和库存保持不变。

先运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，再按审阅结果加 `--apply`。full模式更新根内完整模板，compatible模式只更新modules/meta。已有用户自建同名WORKFLOW_CONTRACT.md或已修改受管文件时拒绝覆盖；先保全、审阅并明确合并方案，不自动替用户移动或删除。compatible宿主根的同名合同、规则与用户内容保持原owner。

保留transaction，以 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览，审阅后加 `--apply`。恢复只回滚本次框架变更，保留项目、私人资料、其他模块改动和客户端Skill副本。独立Meta使用者按其README审阅版本差异和接线，不假设存在AWS事务。Review不自动授予记忆、画像、入库或发布权限。

This minor release updates only Meta to2.1.0. The new workflow contract and Review routes preserve the old Manual anchors. Preview upgrades; unmanaged new-file collisions and edited managed files block overwrite. Compatible mode preserves the host root. Retain the transaction for reviewed rollback. Module integrity, actual upgrade/refusal/recovery and anonymous receipt are separate checks; see docs/releases/2.10.0-validation.md and the independent Meta release notes.
