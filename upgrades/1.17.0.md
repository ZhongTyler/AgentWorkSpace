# Upgrade 1.16.0 → 1.17.0

Adds optional interaction-design and selective GamePresentation UI routing. Skills contains 18 selectable methods. Existing 1.16.0 retrieval lifecycle and Query routing remain unchanged.

Preview and apply the normal workspace upgrade. Only installed packages upgrade; adding the Skills package does not enable client Skills. Then upgrade the already selected game-presentation Skill separately, and explicitly select interaction-design if needed.

For existing frontend-design, review packages/skills/integrations/frontend-design.md and merge only the optional hook. Preserve the original body, license and local edits. The installer does not manage this external file. GamePresentation can use an available Skill, its fixed public reference or equivalent host rules; no mandatory dependency is added.

Package rollback, selected-Skill rollback and manual-hook recovery are separate. Conflicts require review and are never forcibly overwritten. Private research, experiments, frontend originals/backups and host paths are excluded. No models or MCP services start. Engineering checks do not establish long-term trigger rate, experience or time savings.
