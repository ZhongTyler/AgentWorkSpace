# Upgrade 1.8.0 → 1.9.0

Adds an independent optional Tools package and updates Research tool ownership and maintenance guidance. Existing Research integrations helpers stay compatible. No old research evidence, external runtime or client configuration is migrated, deleted or rewritten. Models, accounts, skills and weekly schedules are not installed or enabled by this upgrade.

Preview and apply the ordinary workspace upgrade. Existing selected packages upgrade without automatically selecting Tools. Add Tools separately when wanted:

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
python scripts/workspace.py add --target <workspace> --packages tools
python scripts/workspace.py add --target <workspace> --packages tools --apply
```

Then read modules/tools/README.md. prepare_home.py copies verified templates to a NEW external versioned tools home; it refuses existing directories and managed modules. It performs no downloads, model loads, account queries or client edits. Install only selected tool dependencies there after review. Switching runtime/client paths is a separate host-owned action, with a retained old home and config recovery record.

Keep transaction IDs. Roll back Tools add first, then the workspace upgrade with scripts/workspace.py rollback --target <workspace> --transaction <id> --apply. Reverse any independent client switching yourself before deleting an old runtime; package recovery does not manage it. Local package conflicts refuse partial overwrite, unrelated notes and external runtime/config remain user-owned. Earlier versions follow the published predecessor chain. Tags remain immutable.

Source health verifies inventory, not account connectivity, calibrated decisions, adoption, long-term stability or savings. Optional hosts retain their original flow when tools are missing or unsuitable.
