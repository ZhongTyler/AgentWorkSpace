# Upgrade to 1.22.1

Previous version: 1.22.0. Only Research changes: protocol v0.10, the thin research-study entry, the report template and package introduction. The other eleven component file inventories remain unchanged. This is a method/documentation update, with no installer or runtime changes.

Evaluate ready-made repositories, tools and Skills as usable deliverables, including complete resources, composition, invocation, maintenance and recovery. Compare original direct use, pinned original with a thin adapter, selective reimplementation and non-adoption. Concept overlap alone does not establish equivalent capability; installation does not establish discovery, consumption, adoption or measured benefit.

From the distribution checkout, preview then apply:

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
python scripts/workspace.py status --target <workspace>
python scripts/workspace.py rollback --target <workspace> --transaction <upgrade-transaction>
python scripts/workspace.py rollback --target <workspace> --transaction <upgrade-transaction> --apply
```

Resolve local file conflicts before applying. Rollback restores only transaction-owned bytes and preserves subsequent user edits by refusing conflicting changes. Keep private reports, corpora and runtime outside installed packages. Existing authorizations, Knowledge review, accounts and schedules remain owned by the recipient.

The optional codebase-design, domain-modeling, prototype and writing-for-agents methods are routing examples for recipients who already selected and installed them. This release neither bundles nor installs those external Skills, changes selected-client Skills, adds dependencies or activates services. The maintainer's pinned local installations and experiments are excluded. Their original upstream license and host compatibility must be reviewed separately when selecting them.

Installation and recovery checks do not prove research quality, automatic selection rate or net savings. See [validation and limits](../docs/releases/1.22.1-validation.md).
