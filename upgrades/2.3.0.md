# 2.3.0 升级与恢复

上一正式组合版为 2.2.0。本版只更新独立 Skills 到 2.2.0，其余11个模块固定版本不变。具体方法、适用条件、引用与许可见 Skills README、skills.json 和本版模块升级说明。

先按需 fetch skills，再运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅管理文件和用户修改后加 `--apply`。保留返回的 transaction，回退使用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply`。用户编辑的变化文件拒绝覆盖，无关模块编辑与用户数据保留。

包更新与客户端 Skill 更新分别执行。新版本包内 `python scripts/skills.py upgrade --target <host> --platform codex --apply` 更新已选方法，CodeBuddy 使用 codebuddy 平台参数，各自保留 transaction 并用同一脚本 rollback 恢复。新增方法仍需按名字选择安装，安装方法库不自动启用全部方法。模型、执行器、外部工具与付费服务沿接收方实际能力及授权配置。

旧tag、版本化清单及恢复记录保留。独立模块使用者对照模块本版说明审阅差异；历史组合沿既有升级链抵达 2.2.0，不能跳过前版合同。
