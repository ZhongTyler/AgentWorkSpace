# Upgrade 1.9.0 → 1.10.0

Tools and Research now ship a shared portable policy for assistant-selected local decision models, actual-use/correction/cost observations and periodic per-model/task-profile review. The gateway still executes an explicit backend; no runtime, model, protocol or license is upgraded.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Only selected packages upgrade. Tools remains optional to Research. The recipient explicitly authorizes autonomous selection once for a defined host scope before using it; installation does not enable it, load/download models, connect accounts, register MCP, create schedules or authorize ingestion. Missing or unsuitable tools return to the original path with all source IDs retained. StartLux weights remain noncommercial; Laya remains experimental pending host task evidence.

Read modules/tools/docs/decision-model-policy.md or modules/research/templates/decision-model-policy.md. Keep the active host policy and manual reports/run receipts outside managed modules. Record model_decision, actual tool_usage and model_policy_review; missing cost and old observations stay unknown. Use the existing review window, with Research's default four actual scheduled runs per route; do not create a second schedule or count manual trials. Changing research frequency, installation, licensing or workflow scope retains its authorization gate.

Existing external Tools homes retain their own source/profile/runtime versions. Prepare a fresh versioned home and validate before switching when executable changes are actually needed; this policy-only release does not require a runtime reinstall or client restart. Adopt the new host policy separately and retain its prior version. Already installed client skills are independent; the package upgrade does not overwrite them.

Keep the workspace transaction ID. Preview/apply scripts/workspace.py rollback --target <workspace> --transaction <id> --apply to recover package files. Rollback preserves host rules, policy decisions, research records, external runtimes/weights and client configuration; revert any separately adopted host policy yourself if needed. Local conflicts refuse partial overwrite. Earlier versions follow published predecessors; immutable tags are unchanged.

Validation establishes portable policy, observation fidelity, privacy and install/upgrade/recovery. It does not certify autonomous selection accuracy, calibrated probabilities, long-term quality, adoption or savings.
