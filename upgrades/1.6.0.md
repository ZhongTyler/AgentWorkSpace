# Upgrade 1.5.0 → 1.6.0

This release adds Research as the ninth optional package. Existing package selections, paths and host authority stay intact. An upgrade does not install Research, migrate research reports, enable a scheduler, connect accounts, install MCP/media dependencies or authorize Knowledge ingestion. Research has no required package; Knowledge and game-analysis integration are optional and follow the installed host contracts. Review overlapping research workflows semantically before integration.

本版提供 MD/网址/问题入口、通用及游戏来源、字幕/多图读取路径和主动探索模板。有用增量、新保留条件候选即使暂不采用也简报一次；重复或无价值轮次静默。初始调度模板为周一/周四通用10:00、游戏18:00（Asia/Shanghai），由接收者授权后在宿主创建。频率分别评估，调整需本人批准。安装不继承维护者授权、任务或私人报告。

## Install and upgrade

Use Python 3.10+ and keep this distribution separate from the target workspace. Review first; apply only selected changes:

```text
python scripts/workspace.py upgrade --target <workspace-path>
python scripts/workspace.py upgrade --target <workspace-path> --apply
python scripts/workspace.py audit --target <workspace-path> --needs research
python scripts/workspace.py add --target <workspace-path> --packages research
python scripts/workspace.py add --target <workspace-path> --packages research --apply
```

For a host without this installer, use `init --mode compatible --packages research`; Research alone needs no profile or meta. Read modules/research/README.md. Keep new reports, media and queues in a user-owned directory outside modules/research. Review actual sources, account permissions and capture coverage per task; catalog inclusion does not mean connection success. Video transcripts are paired with checked key frames, and OCR does not certify diagram meaning.

## Recovery and verification boundaries

Record each returned transaction ID. Roll back the Research add before the preceding upgrade. Preview conflicts and preserve user edits:

```text
python scripts/workspace.py rollback --target <workspace-path> --transaction <transaction-id>
python scripts/workspace.py rollback --target <workspace-path> --transaction <transaction-id> --apply
```

Rollback restores installer-owned files only; reports outside the package remain user-owned. Historical tags are immutable. Release checks cover standalone install, repeat install, package review, explicit add, real 1.5.0 upgrade and reverse rollback, archive hashes and private-input rejection on Windows. They do not prove all live services, other platforms, recipient authorization, research accuracy, adoption or long-term benefit. The Research source marker records its committed public inputs; private maintenance history is not shipped.
