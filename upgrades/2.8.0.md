# 2.8.0 升级与恢复

从 2.7.0 更新 Skills 2.3.1、GamePresentation 2.1.0 和 Research 2.3.0；其余9个模块固定身份不变。新增方法和可选配合见各模块说明，不以安装数量代表实际效果。

先按需 fetch，再运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅后加 `--apply`。受影响文件的用户编辑会阻止覆盖，未改变模块、宿主规则、项目、私人资料及已安装客户端方法保持。保留 transaction，用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply` 回退。

Skills 包更新不会自动更新已有 Codex/CodeBuddy 方法副本。分别运行该包的 `scripts/skills.py upgrade --target <workspace> --platform <codex|codebuddy>` 预览与显式应用，保留各客户端 transaction；发生编辑冲突先处理原副本。新增方法按需安装，不自动启用整个库。客户端方法回退与 AWS 包回退分开进行。

Research 清单模板只用于用户指定的包外位置，已有队列沿原 ID 续接，不批量覆盖或自动创建研究/调度。GamePresentation 的验证方法可直接使用；未附带私人 Studio 或未发布的角色生产链。没有其他模块时沿包内方法继续，数据、来源、审阅与实际接受状态由原 owner 负责。不启动服务、模型或个人网站部署。

Skills 2.3.0 的方法和匿名业务检查通过，但提交缺少工作区 Closure 尾注，原始失败及 tag 不改。2.3.1 仅修包装版本和提交元数据；285份方法、文案、许可及执行代码逐字节不变。已有2.2.2客户端先按独立包的说明升级到2.3.0，再到2.3.1；包升级不自动更新客户端。两平台真实2.3.0升级及回退通过。
