# Upgrade1.13.1 →1.14.0

Adds the supervised local-image workflow to Tools, optional review-only consumption to GamePresentation, and routing in the selected game-presentation Skill. FLUX/Anima/Z and optional matting/composition/upscale maintenance sources are included; weights and runtime are not. Other packages and existing dependencies remain unchanged.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Keep the transaction ID and review changed library files. Rollback using scripts/workspace.py rollback --target <workspace> --transaction <id>, preview first, then --apply. Edited managed library files remain conflicts; external model homes, images, user projects, credentials and host authority are preserved. Skills already installed into .agents/.codebuddy have their own scripts/skills.py upgrade/rollback transactions; package upgrade does not silently replace those copies. The Skills selected-library version advances from1.12.0 to1.14.0.

New packages remain optional: use add with an explicit selection; no automatic Tools install, model download, cloud call, schedule, client configuration, system change or cleanup permission. Prepare a new external Tools home, review fixed component source and license, then validate on recipient hardware. The setup guide describes manual restoration and has no clean-machine network-install certification.

The workflow is supervised: source quality, target-size preview, rights, producer adoption and real-engine acceptance are separate. Memory preflight is a minimum exclusion gate, not a stable-batch guarantee. Rebooting with the maintainer's original8/16GB pagefile exposed commit exhaustion even with spare VRAM. Anima offline output permission is distinct from commercial model-service eligibility. CPP and SDXL/IP did not pass frozen quality/increment gates; SANA hit memory stops before images, so quality/cooperation remain unevaluated. The package preserves these limits instead of promoting rejected routes.

Existing runtime stays usable through its prior external home. Switch to a new home only after local verification; rollback the library independently. No old released tag is rewritten. See Tools docs/local-image-validation.md for bounded measurements and unknown cost/quality dimensions.
