# Upgrade 1.13.0 → 1.13.1

Adds a portable Research validation guide and an empty candidate template. Manual research and existing weekly routes check candidates before choosing a topic, save actual evidence in the original report, update the user's external index and review backlog in the existing four-run window.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Installed package files are library instructions. Keep candidate details, reports, user decisions and chat links in the user's external research directory. Installation does not create a private candidate list, enable schedules, run experiments, download tools/models, authorize cleanup or approve Knowledge ingestion. Existing host authority, account configuration, runtime and package selections remain.

This is compatible with 1.13.0. Existing Research installations gain two guide/template files and updated routing; other package bytes remain unchanged. A host without Research is not auto-enrolled: explicitly select the package through the existing add flow if needed. Existing research workflows still require semantic compatibility review.

Keep the upgrade transaction ID. Preview reverse recovery with scripts/workspace.py rollback --target <workspace> --transaction <id>, then use --apply only after resolving library edits. Rollback restores managed library files and removes newly managed guide/template files; it does not touch external candidate lists, reports, client configuration, models or user projects. Changed library files remain conflicts. Published predecessors/tags are immutable.

Validation covers privacy filtering, scoped publication, real predecessor upgrade/conflicts/rollback and standalone installation on Windows. It does not prove future Agent compliance, research quality or net time/cost savings. Existing notification and frequency choices remain under the recipient's authority.
