# Upgrade 1.12.1 → 1.13.0

Adds GameProject as an independent optional package, with Godot project workspace template 0.2.4. Existing package selections and capabilities remain. The upgrade does not add GameProject, create an engine, initialize Git, migrate prototypes, enable tools or rewrite projects.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
python scripts/workspace.py audit --target <workspace> --needs game-project
python scripts/workspace.py add --target <workspace> --packages game-project
python scripts/workspace.py add --target <workspace> --packages game-project --apply
```

Read modules/game-project/README.md. Review existing project templates, maintenance, decisions, assets, engine boundaries and recovery before adoption. A reviewed equivalent provider can satisfy game-project-workspace without installing this package; matching folder names and structural health alone cannot prove semantic compatibility. Standalone compatible installation has no required package.

Create only a new external directory using the package's preview/apply creator. Python 3.10+ creates the workspace; Node.js 22+ checks maintenance. Engine creation and actual Godot execution are separate project actions. Existing projects use selective, reviewed template upgrades, never a full overwrite. Their configured template version stays tied to the copied baseline rather than being automatically advanced by a library update.

Keep workspace transaction IDs. Roll back the GameProject add first, then the workspace upgrade with scripts/workspace.py rollback --target <workspace> --transaction <id>; preview before --apply. Package recovery manages library files, not external project copies, their facts/customizations, engine, assets, runtime or client configuration. Later user edits to a library file remain conflicts. Existing projects still work after the library is removed.

Earlier versions follow declared predecessors; published tags are immutable. Validation covers empty-template maintenance, ownership and creation failures, install/upgrade/conflicts and reverse recovery on Windows. It does not establish a playable game, engine compatibility on every platform, real playtest acceptance or long-term development benefit.
