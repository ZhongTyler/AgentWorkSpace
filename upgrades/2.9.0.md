# 2.9.0 升级与恢复

从 2.8.0 更新 Tools 到2.3.0，增加 copy-polish 和 codex-context-budget；其余11个模块的固定身份不变。工具包共19项工具、17条工作流，按需选择。

先按需 fetch，再运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅后加 `--apply`。用户修改会阻止覆盖，未改变模块、宿主规则、项目、私人资料和客户端 Skill 副本保持。保留 transaction，用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply` 回退。

Tools 包升级不更新已有包外运行环境。通过 `prepare_home.py --home <new-external-home>` 准备不存在的新目录，独立核对完整性与配置后切换调用方；保留旧 home。用户 provider 配置、诊断输出与实际材料保存在包外，不放入发布库存。copy-polish 默认可使用离线响应样例；真实调用需要使用者显式配置兼容 Gemini 原生接口的 HTTPS 服务、模型和密钥环境变量，并授权文本外发及费用。合成测试没有验证实际服务质量。

codex-context-budget 的安装先预览，指定独立 `--codex-home` 后才可显式应用。只合并本工具的四类 hook，卸载保留其他配置。工具包安装不会自动启用客户端 hook；接收方应检查客户端信任与实际覆盖。预算按反馈字节估算，超量反馈裁剪不撤销工具已产生的副作用。回退 Tools 包与恢复/卸载客户端 hook、provider 配置分别处理，详见 Tools 的版本说明。
