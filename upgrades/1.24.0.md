# 1.24.0 升级与恢复

直接前一版为 **1.23.0**。仅 meta、Skills、GamePresentation 和 Travel 的文件库存变化；其他组件保持原样，无新增必装包、账号、服务或付费调用。

## 变更与接入

- Skills 从19项增至21项，新增 `design-critique` 与 `design-handoff`。保留固定上游原件、Apache-2.0许可、连接器参考和便携薄适配；分别选装即可，不需要meta、Tools或Figma。meta与游戏表现入口只按当前评审/实现规格缺口选择，不改变已有项目决定。
- Travel通用工作流从0.4.6升级到0.5.0，补充设计基线、组件与事实绑定、国内高德/境外Google Maps选路、正文事实引用和结论级溯源。私有旅行、订单、偏好、图片和网站均不随包发布。
- 新合同与溯源字段按需要引入现有项目；包升级不迁移旧旅行schema，不重写行程或已生成网站，也不自动生成前端设计合同。沿Travel包内运行说明审阅本项目的事实源和消费者。文本扫描只给复查线索，不代替语义阅读。

## 顺序

```text
python scripts/workspace.py upgrade --target <workspace-path>
python scripts/workspace.py upgrade --target <workspace-path> --apply
python <workspace-path>/modules/skills/scripts/skills.py upgrade --target <workspace-path>
python <workspace-path>/modules/skills/scripts/skills.py upgrade --target <workspace-path> --apply
python <workspace-path>/modules/skills/scripts/skills.py install --target <workspace-path> --names design-critique design-handoff
python <workspace-path>/modules/skills/scripts/skills.py install --target <workspace-path> --names design-critique design-handoff --apply
```

只运行已选包需要的步骤；未安装的包不会自动增加。CodeBuddy选择工具另加`--platform codebuddy`。package升级与客户端Skill升级是独立事务；新增方法需要明确选装，不接管宿主现有同名Skill，也不修改外部frontend或第三方插件。遇到用户与上游同时修改同一文件，先保留并审阅冲突。

## 恢复与验证边界

保存每次应用返回的事务ID。按相反顺序先回退本次新增客户端Skill，再回退其升级，最后用`workspace.py rollback`预览并恢复包。后改文件会阻断回退；不要为回到旧版覆盖后续修改。外部旅行、宿主规则、手动frontend接线与已生成产物不归安装器事务所有，按各自恢复点管理。

Travel第三项独立参与者试用已取消，本版没有此项验收；复制/合成夹具测试只证明工程行为。两个设计Skill的自动匹配、跨项目效果及长期省工继续待观察，原版的可安装性和局部案例不构成通用效果保证。详见[验证与限制](../docs/releases/1.24.0-validation.md)。
