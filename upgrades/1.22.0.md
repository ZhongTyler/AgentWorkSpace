# Upgrade to 1.22.0

Previous version: 1.21.1. This release changes only the Skills package: 19 selectable methods, adding citation-management with eight scripts, references, templates, MIT license and provenance. The other eleven component file inventories remain unchanged. Root bilingual Skill counts and release documentation reflect this addition.

From the distribution checkout, preview then apply:

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
python scripts/workspace.py status --target <workspace>
python scripts/workspace.py rollback --target <workspace> --transaction <package-transaction>
python scripts/workspace.py rollback --target <workspace> --transaction <package-transaction> --apply
```

Resolve reported local file conflicts before applying; do not overwrite recipient work. Keep the package transaction ID for recovery. Upgrading does not add an unselected Skills package or enable citation-management. If Skills is selected, use its installed scripts/skills.py to preview and explicitly install citation-management. An existing differing client Skill is preserved. Selected-Skill upgrades and rollback have their own transaction IDs; the prior selected-Skill catalog is 1.20.1.

The installer remains Python 3.10+ with no third-party dependencies. Offline BibTeX formatting uses standard Python; online citation scripts may require requests and optional scholarly. No dependencies, plugins, accounts, services or schedules are activated. Package and selected-Skill installation do not run those scripts, query the network or change Knowledge/user research data.

This release does not distribute the maintainer's local Codex inventory, plugin/system Skills, runtime identity files or host adapters. Metadata checking does not establish that a paper supports a claim. Packaging and offline probes do not demonstrate online service availability or improved research quality. See [validation and limits](../docs/releases/1.22.0-validation.md).
