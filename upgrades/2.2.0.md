# 2.2.0 升级与恢复

上一正式组合版为 2.1.0。本版只更新 Knowledge 到独立模块 2.1.0；其余 11 个固定模块版本及公开提交保持不变。

Knowledge 新消化统一自动 deferred/core/consolidated-v1，保留阶段恢复点及最终精确版本确认。历史运行沿冻结策略继续，升级不改运行清单或旧批准。Query 增加 DomainGroup 和相关页导航、Raw→Clippings 溯源；增强独立审核由可信宿主显式启用，默认直接交付正文。可选 Tools/BM25/hybrid 与反馈接口的绑定和同意由接收方拥有，安装不启动索引、在线服务或付费调用。

从新分发目录先运行 `python scripts/workspace.py fetch --packages knowledge --apply`，再预览 `python scripts/workspace.py upgrade --target <workspace>`，核对已安装模块、同类流程、managed 文件差异和用户修改，确认后加 `--apply`。未安装 Knowledge 的工作区不会因组合升级自动装入它。全量获取须显式 `fetch --all --apply`。

成功写入会返回 transaction。保留该 ID，使用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览，再加 `--apply` 回退。修改过的管理文件会拒绝覆盖，先保全并处理具体差异；本地知识、配置、索引、运行、项目和宿主规则仍属各自 owner。已有独立模块实例保留位置与 Git 所有权，版本不同的实例按其自身升级合同审阅。

独立使用 Knowledge 时，保留原版本与用户数据作为恢复点，对照 [模块升级说明](../packages/knowledge/docs/releases/2.1.0.md)接收审过的框架差异并验证库存，不迁移历史 run。更早版本先沿各自历史升级链抵达 2.1.0。旧公开 tag 和附件均保留。
