从2.10.0更新 Knowledge2.1.1 至2.1.2，仅修复Wiki使用说明中三处链接规则断锚，并校正两个章节标注。新增原生导航回归。链接政策正文、Query/Ingest代码及其他11模块版本、提交和库存保持不变。

先运行 `python scripts/workspace.py upgrade --target <workspace>` 预览，审阅后加 `--apply`。受管文件有用户修改时拒绝覆盖；先保全、审阅和处理差异。full与compatible模式均保持原接入方式，宿主规则、私人资料、用户知识、项目及已有客户端Skill保留原owner。独立Knowledge实例按其README/版本差异审阅，不自动覆盖。

保留transaction，以 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览，审阅后加 `--apply`。只恢复本次框架变更，保留其他模块和用户资料。升级不启动消化、索引、模型或服务，不部署网站。

This patch updates only Knowledge navigation and its regression, retaining all eleven other fixed module identities. Preview upgrades; edited managed files block overwrite. Retain the transaction for reviewed rollback. See the Knowledge release notes and docs/releases/2.10.1-validation.md for exact coverage.
