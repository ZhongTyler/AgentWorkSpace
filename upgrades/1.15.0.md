# Upgrade 1.14.1 → 1.15.0

Adds the optional Tools retrieval core and the Knowledge thin consumer. BM25 is the configured discovery default; hybrid is explicit and requires recipient-reviewed local assets. Original Query remains available without Tools, Python, an index or local binding. Only Tools and Knowledge package inventories change; other components and user knowledge stay unchanged.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Run from this release repository. Review conflicts rather than overwriting user edits. Tools is optional: explicitly add it if desired, prepare its versioned external home, then follow its retrieval guide to build an index from a reviewed source commit. A fresh empty Knowledge library continues to answer gaps through original Query; installation does not initialize an index, call a model or change a recipient's source approval.

The pack is a derived read-only view, not another editable knowledge store. Keep source IDs, source bytes, the reviewed commit, pack hash and embedding profile. Local binding and all indexes, models, runtime, accounts and knowledge content remain outside the release. Ordinary discovery/read never rebuilds or writes. Missing tools, unavailable hybrid or stale sources return to original Query with a reason. Core understanding and important claims still require the original full Wiki/Raw path and review.

The local and future website adapter share search/context/read, version and permission-view protocols. The reference HTTP server is loopback only. Website identity, current account scope, provider, tokens, TLS, cancellation, cache and deployment remain the receiving host's responsibility. This release does not deploy a site, publish a recipient's knowledge, ship subscription credentials or enable MCP/schedules.

For recovery, preview then apply `python scripts/workspace.py rollback --target <workspace> --transaction <upgrade-id>`. The package transaction restores managed files; external Tools homes and private Knowledge remain. To disable retrieval immediately, select legacy or restore/remove the local binding under the recipient's authority. Keep the previous version home until the new one is validated. Do not edit or delete private knowledge to repair an index.

Six unrelated Knowledge maintenance files retain the exact previous public source runtime, explicitly pinned in its source manifest. Private adjudication and migration maintenance are not silently included. Validation covers engineering, installation, immediate-predecessor upgrade/conflicts/reverse recovery and synthetic cross-package queries; it does not prove general answer superiority, lower model bills or production website acceptance.
