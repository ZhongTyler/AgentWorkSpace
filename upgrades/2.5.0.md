# 2.5.0 升级与恢复

上一正式组合为 2.4.1。本次仅更新独立 Tools 至 2.1.0；其余11个模块固定身份不变。公开内容、依赖、来源与验证范围以 Tools 本版说明为准。运行环境、模型、账号和私人结果不随模块升级迁移。

先按需获取 Tools，运行 `python scripts/workspace.py upgrade --target <workspace>` 审阅差异，确认后加 `--apply`。用户编辑的受影响文件拒绝覆盖；已有宿主规则、项目、私人材料及未改模块的用户编辑保持。保留 transaction，通过 `python scripts/workspace.py rollback --target <workspace> --transaction <id>` 预览并加 `--apply` 回退。

Tools 使用包外版本化 home。先在新外部目录显式 prepare_home，再自行准备所需依赖并验证，最后切换调用方；旧 home 作为恢复入口保留。安装或升级包不下载模型、不启动或注册服务、不变更账号，不替代使用者的实际运行验证。原有客户端 Skill 安装记录不因 Tools 更新而变化。

知识反馈的数据恢复与包回退分开：新 reader 可以读旧记录；显式调用 resolveIssue 写入 resolved 后，旧 2.0.0 reader 会拒绝同一 store。启用前保留批准的快照或独立 namespace/home。需要旧 reader 时保留新 store，在另处恢复升级前快照；也可继续用新 reader。不能通过改写或删去原日志来消除差异。详见 [Tools 本版升级与反馈数据说明](https://github.com/ZhongTyler/AWS-Tools/blob/v2.1.0/docs/release-2.1.0.md)。
