# 1.21.0：可选的 MCP 共享按需入口

直接前一版 1.20.1。只更新 Tools 包中的通用 Windows MCP 运行库、明确选择的 STDIO 安装器及公开说明；发布器增加精确源白名单。其他十一组件的内容库存保持不变。包总数仍为十一（另有 meta），不新增 Skill、模型、账号或调度。

先用 workspace.py upgrade 预览，再显式 --apply。full 与 compatible 沿各自现有规则；兼容模式不覆盖根宿主权威。本地改动报告冲突。没有选 Tools 的工作区不会自动安装它。

工具源更新与运行适配分开：先用 Tools/prepare_home.py 准备全新的包外工具 home，再阅读 integrations/mcp/demand/README.md。plan 只读；prepare 明确执行所选原生 MCP 目录捕获；apply 才切换那些配置段。默认不修改核心卸载键；显式选择较短等待时严格验证已测试版本。既有连接保留到自然卸载或用户安全重启。

公开安装器不修改插件缓存或原生 CUA；也不迁移维护者加密 profiles、实际目录、客户端配置或本机运行环境。有状态后台默认每会话隔离，只读无状态来源须另外明确选择共享。特殊编辑器/外部模型 owner 适配不能直接套用。

恢复分两层：先按私有 runtime home 执行 demand_portable_install.py rollback，保留当前连接与其他配置；包源若需恢复，再回退 workspace.py 的包事务。外部 home 不被包回退删除，不停止其他任务。本地重叠配置编辑会拒绝覆盖，保留待人工核对的恢复记录。

Windows 合成回归验证共享目录不启动业务、首次调用才启动、会话状态隔离、owner 退出只释放自身、网关自然退出；原有相关回归另测。冷态内存观察有固定版本与工作负载边界，不保证所有机器或繁忙态收益。本次不部署个人网站；网站旧版固定链接保持其历史范围。
