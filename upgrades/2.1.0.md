# 2.1.0 升级与恢复

上一正式组合版为 2.0.0。本版更新 GameProject、FromDemoToSpec、Skills、Research、GameAnalysisDecision 五个独立模块到 2.1.0，其余固定模块版本沿用 2.0.0。

先从新版本分发目录预览 `python scripts/workspace.py upgrade --target <workspace>`，核对所选模块、已有实例、文件冲突与可选接线，再加 `--apply`。按需先用 fetch 获取所需模块。已有独立模块实例保留原路径和 Git 所有权，版本不同的实例按其维护合同单独审阅升级。

每次成功写入返回 transaction。保留该 ID，回退预览使用 `python scripts/workspace.py rollback --target <workspace> --transaction <id>`，核对后加 `--apply`。用户改过的管理文件会形成冲突，先保全并处理具体差异。项目、报告、账号及运行环境由各自 owner 维护。

Skills 包升级和已安装客户端 Skill 升级分别执行。包内 `scripts/skills.py upgrade --target <host> --platform codex --apply` 更新 Codex 已选方法，CodeBuddy 使用其对应平台参数。每个客户端使用自己的 transaction 回退。新增方法仍按名字选择安装。

GameProject 包更新模板库。已有游戏项目按其选择性升级合同接收 0.2.21 模板或资源工作台变化，保留现有清单、审阅及工程定制。新的 HTML 模板携带固定的项目状态支持，无须安装 FromDemoToSpec；联动后按现有设计、状态、证据和恢复合同交接。

GAD 输出准备好的调查任务，实际角色发现、委派、模型和授权由宿主提供。Research 按接收方范围核对 HTML 运行资源、来源链接和附件依赖。业务条件与人工验收沿具体模块合同执行。

1.30.0 用户先沿 2.0.0 的原迁移路径升级到 2.0.0，再按本指南推进。旧 tag 与附件保持原身份。
