## Review and upgrade

Use this release from a directory outside the recipient workspace. Audit existing modules and workflows using docs/compatible-workspace.md, then preview and apply the package transaction.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Resolve owner-edited file conflicts before applying. Private reports, bindings, cost records, project assets and installed runtime retain their recipient-owned locations. Keep the transaction ID for recovery.

Client methods use a separate transaction after the package update.

```text
python <workspace>/modules/skills/scripts/skills.py upgrade --target <workspace> --apply
python <workspace>/modules/skills/scripts/skills.py install --target <workspace> --names task-tooling research-collection game-evidence-collection opportunity-flow --apply
```
