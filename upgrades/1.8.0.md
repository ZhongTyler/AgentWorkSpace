# Upgrade 1.7.0 → 1.8.0

Game development support now includes optional Research/REA artifact investigation. This release updates meta's common support guidance, the portable game-decision-support method in Skills, and Research's development-support guide. No package becomes a mandatory dependency of another.

Preview the unified workspace upgrade, then apply without conflicts:

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Only selected packages are upgraded. Existing user reports, host authority, local edits and external tool/client directories remain user-owned. Compatible hosts still review workflow overlap; the support route supplements their existing process. Missing Research/REA continues ordinary source/material analysis. Full source is read directly when sufficient; artifact investigation never substitutes for real Play or a product decision.

## Separately upgrade a selected skill

The workspace package update refreshes the method library, not already installed client skills. If game-decision-support is installed through the Skills package, run from modules/skills:

```text
python scripts/skills.py upgrade --target <workspace>
python scripts/skills.py upgrade --target <workspace> --apply
```

Only previously selected skills are upgraded, and conflicting edits are refused. Installing the package does not enable new skills, download REA runtime, register MCP, install native engines, run targets, connect accounts, start weekly research or authorize Knowledge ingestion. REA setup remains an explicit operation described in the Research package. Existing REA 6.4.0 locks and runtime behavior are unchanged.

## Recovery

Keep both transaction IDs. Roll back the selected-skill transaction first with scripts/skills.py rollback, then preview/apply scripts/workspace.py rollback using the workspace transaction. Rollback preserves user-owned notes and external tool/client directories. Package/skill rollback does not revert independent REA runtime, global rea-investigate installation, MCP configuration or account state. Never overwrite an entire client configuration from an old backup after unrelated changes.

Earlier workspace versions follow the documented release chain, not a direct skip to 1.8.0. The portable Skills library changes from its prior 1.3.1 label to 1.8.0; other methods retain their content. This is install/upgrade/routing validation, not proof of automatic selection accuracy or game-development benefit. Historical tags remain immutable.
