# Upgrade 1.14.0 → 1.14.1

Adds a shared observation/tuning/reproduction/comparison/recovery method in meta, optional feedback-loop thin Skill, and direct entry points in FromDemoToSpec, GamePresentation, Research and GameProject template 0.2.5. Other component inventories stay unchanged. This is compatible with the immediately previous version; old immutable tags are retained.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
python modules/skills/scripts/skills.py install --target <workspace> --names feedback-loop
python modules/skills/scripts/skills.py install --target <workspace> --names feedback-loop --apply
```

Run workspace commands from this release repository and selected-Skill commands from the receiving workspace. Add Skills explicitly if not selected. A library upgrade never enables the new Skill automatically. Its body routes to the host's shared method; without meta it offers this release's public method link and does not require the whole framework. When existing tools are enough, reuse them; normal one-off changes do not create a workbench. The method covers gameplay/numbers, AI, input, generation, performance, presentation/audio and other development experiments.

Installation does not create experiment tools, load a model, register MCP, enable schedules, run tests on user projects, restore frozen projects, change decisions/configuration/saves or grant permissions. Private reports, experiments and the maintainer's game copies are excluded. New GameProject copies use template 0.2.5; existing projects retain their own versions and adopt selected changes under their own owner.

Keep both workspace and selected-Skill transaction IDs. Roll back selected feedback-loop installation first with modules/skills/scripts/skills.py rollback --target <workspace> --transaction <id>, preview then --apply; then roll back the workspace package transaction with scripts/workspace.py rollback. User edits remain conflicts. External projects, research notes, model/runtime/client data and decisions stay outside package recovery.

Validation covers portable references, privacy exclusions, actual selected installation, predecessor upgrade/conflict/reverse recovery and new template creation on Windows. Private research reports and experimental game copies are not part of this release. It does not establish automatic triggering in every host, gameplay quality, long-term cost savings, universal browser/engine support or producer acceptance.
