# Upgrade 1.12.0 → 1.12.1

This patch adds an outcome follow-up to the portable meta support/learning guidance. When material changes a decision or is adopted, revisit its actual result at the next relevant verification or milestone in the host's existing record. Retain applicability/version and distinguish support, no benefit, counterexamples and unknown. Reading counts or an Agent's adoption claim do not prove effectiveness.

```text
python scripts/workspace.py upgrade --target <workspace>
python scripts/workspace.py upgrade --target <workspace> --apply
```

Only installed components update. Existing host authority, project decisions, private records, accounts, schedules and runtime remain owned by the recipient. No new ledger, automatic ingestion, research run or human playtest is required. No schema or production installer behavior changes.

The asynchronous verification guidance in workflow-closure was already published in 1.12.0 and is retained. Bind the actual task/version/instance, wait within bounds for a terminal result, then verify it. An old successful run or started process cannot establish this run's completion.

The selected-client Skill catalog remains 1.12.0 because this patch does not change its files. Workspace package upgrades and selected-client Skill upgrades are separate. A Skill already upgraded to selected catalog 1.12.0 needs no additional selected-Skill upgrade for this patch. Older selected Skills follow modules/skills/upgrades/1.12.0.md and its supported predecessor chain; do not relabel state manually.

Keep the workspace upgrade transaction ID. Preview conflicts before applying. Rollback restores managed workspace files to 1.12.0 while preserving host rules, private content and independent client/runtime state. Any separately performed selected-Skill upgrade has its own transaction and reverse rollback. Earlier release tags remain unchanged.

Verification covers engineering installation, actual predecessor upgrade, conflict refusal and recovery; it does not establish real-task time savings or knowledge quality. See [release verification](../docs/releases/1.12.1-validation.md).
