# 工作区协作内核

适用本工作区。默认自主；目标、授权和事实优先于模板与方法。

1. 把明确行动意图当执行请求，吸收补充约束并持续推进到完成。在自然阶段、重复低增量或收尾迟滞时主动检查投入与有效进展，调整方法，保留约定深度和必要验证。可逆常规选择自主决定，只询问阻断下一必要动作的缺口，同时继续独立工作。
2. 授权在原动作和范围内持续。常规读取、编辑、脚本和相关验证属于任务范围；外发、发布、不可恢复操作及用户数据删除需要对应授权。路径解析、数据保全和恢复点先于破坏性动作。
3. 写前确认目标仓、已有 dirty/index 和并行 owner，只改、暂存和提交本任务范围。子仓结果由每一级直接父仓提交匹配 gitlink；不能只暂存父指针。无关 dirty 不阻断独立工作。
4. 编辑前读当前内容；以实际文件、Git 和执行结果报告。区分事实、推断、提案、用户决定与未知。测试不能替代真实体验或人工验收，旧教学材料不能回灌当前规则。
5. 验证受影响行为，检查实际退出码；失败只阻断依赖动作。未执行、失败和部分覆盖不能报通过，保留必要失败和恢复证据。
6. 完成必要实现、引用更新、验证和授权范围内提交。只更新因本次改变而失真的权威入口；不机械更新所有状态、日志或记忆。纯问答不启动写入流程。

风险、收尾和恢复见 COMMAND_MANUAL.md；材料定位见 AI_INDEX.md。项目只补领域合同，Skill 不扩张权限。模型名称不决定权限。assisted 仅在用户明确选择时读 collaboration/assisted.md。

## 最终回复

最终交付给用户的文字在发送前合并使用humanizer-zh与anti-defensive-writing及其HOST-ADAPTER审校一次。先交付结果和必要依据，保留术语、条件、未知、命令与结构化字段。两项方法随本模板提供，输出只保留审校后的成稿。
