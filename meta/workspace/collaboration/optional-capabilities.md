# 按需接入能力与既有流程

先明确当前任务缺什么，再检查工作区已有模块、工作流、工具和权限。能满足同一能力的既有实现优先复用；名称不同不代表缺依赖。安装 package 前审阅可能重叠的入口、数据归属、触发方式和升级方式，按当前需要决定复用、适配、并存或暂不安装。审计结果是当前接线判断，不自动授权改写宿主规则。

## 知识、研究与复利

普通查询可以单独运行 Knowledge，原始研究档案也可以单独保存在 Research。需要跨库依据时，使用接收方明确配置的报告目录和存储绑定，区分发现候选、实际阅读、来源验证和采用。未读、失效、未接受或部分覆盖的资料保持其真实状态，不把目录存在当成研究完成。

Tools 的知识复利核心可选。宿主按 host/library/view 隔离本题查阅；返回、阅读、采用和效果分别记录。只有实际有语义增量且策略允许时，才在显式的外部私人目录中保留；没有增量轻量结束。缺少核心、绑定被禁用、保留策略不成立或存储失败时，普通任务仍可完成。公开包不携带私人报告、线上拉取任务或作者账号。

Knowledge 的合并 Ingest 流程可以复用 Raw/Wiki 写作者，由主审核者对冻结输入和外部写作结果负责；写作者不能自验通过。模型与会话以接收方实际配置和授权为准。精确版本批准、历史运行保全、失败恢复与实际成本由该包控制器解释，配置存在不等于真实执行或用户接受。

## 可选方法和工具

Skills 库提供开发接口设计、领域建模、探索原型、Agent 文档、评测结果分析及 Finesse UI 参考，按任务缺口选择。已有界面设计和工作流可继续使用，不因库中存在多个方法就重复走流程。

Tools 另提供匿名 B站字幕/稀疏画面/按需音轨、可选 ASR、明确口径的离线排盘、MCP 已知版本恢复及只读协作检查。安装只复制源码；运行环境恢复、模型准备、MCP 注册、账号使用、服务启动、其他会话消息和外发发布是各自独立的动作，按当前授权处理。

提交信息和 Gitlink 检查读取实际 Git 对象；协作诊断报告启发式候选，不授予权限、不自动修复，也不能代替项目验收。工具未配置或不适用时，沿原任务方式继续并说明实际限制。已有项目与新包之间需要具体适配时，先完成有界审阅，再决定实现，避免平行建立同职责流程。
