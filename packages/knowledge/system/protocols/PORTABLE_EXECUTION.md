# Portable Ingest and Query execution

The existing interactive/deferred review contracts remain valid for historical runs. New core deferred runs may use consolidated-v1, the frozen content-writer/main-reviewer pipeline and Stage3 finalizer. `ingest-control.ps1` creates and records the execution profile; `node system/maintenance/checklists/ingest-advance.mjs --root <Knowledge> --run <run.json>` reports the next bounded operation. Inspect that output before acting. It does not grant permission to launch agents, message chats, use paid models, approve content or publish.

Raw and Wiki may share a writer; the main reviewer verifies frozen inputs and externally produced content. A writer cannot accept its own revision. Model/effort defaults in ingest-agent-policy.json are upstream configuration examples: the recipient must verify availability and set its own supported choices before dispatch. Optional session bindings belong in ingest-agent-bindings.local.json and must follow the host's user-authorization rules. The package never creates or messages sessions on installation. Preserve real host receipts; synthetic fixtures cannot satisfy human/host-observed acceptance.

The writing contract packaged as raw-writing-v2.md supplies portable style boundaries; no private author samples are required. Unchanged metadata-only evidence may be reused only when the controller proves matching content identity. Changed content, unresolved findings, stale approval, unsupported legacy migration or incomplete cost data retain their real state. Final approval binds the exact review version and content manifest, and consolidated finish goes through the finalizer.

Query continues to distinguish discovery, actual read, source verification and use. Optional research reports use a zero-state catalog and explicit storage bindings. Optional compounding uses a receiver-defined host/library/view, external private home and explicit retention policy; missing/disabled/no_increment paths preserve the original result. SDK/native live-session integration, author service deployments, private corpora and installed runtime are outside this portable package.
