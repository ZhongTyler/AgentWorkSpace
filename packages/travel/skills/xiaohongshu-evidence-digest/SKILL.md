# Digest evidence

Read [topic workflow](../../流程/03-主题知识与综合分析.md) and [review contract](../../运行/数据合同.md). Work on selected IDs, not an unbounded library.

1. Run source-audit; open raw source.json and gallery output. Read body and every image at legible resolution. Missing image tools/unreadable content or declared partial/unknown original capture means partial, even if all saved images were read. Legacy capture coverage remains unknown; never retrofit a full-capture claim.
2. Separate experience, image text, official current facts, inference and unknowns. Verify changing rules with official pages; record URL/date.
3. Update topic Wiki, not date appendices. Conclusions first, source note URLs last with a sentence explaining reading value. Raw remains intact.
4. Review JSON declares topic destinations/reasons and every image hash. Complete/not-used requires actual body/all-image reading. Excluded-before-reading is screen, not not-used.
5. Run digest with current rawHash, research-status, validate. Hash binds input, not truth. Source refresh requires actual re-review, not hash replacement.

Report selected/extracted/complete/partial/not-used/failed counts, IDs, Wiki destinations and decision impacts. A source in three topics counts once. Never promote historical prices/weather/availability to present guarantees.
