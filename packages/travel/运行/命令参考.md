# CLI命令与副作用

`node scripts/travel.mjs quality --project <项目目录>`：输出体验步骤、专题关联、图片覆盖、阅读提示和输入指纹。它不判定语义、视觉或人工验收；见[品质复现与验收](品质复现与验收.md)。

终端在本包根；统一前缀 node scripts/travel.mjs。所有JSON输入UTF-8；目录带空格加引号。未知参数立即报错，错误退出码为1；JSON输出供模型/脚本读取。

|命令|参数（可选项用方括号）|写入|
|---|---|---|
|doctor / help / package-check|无|只读环境、参数、包内链接/语法|
|init|--project 新目录 --title 标题 --start 日期 --end 日期|新骨架；已有目录拒绝|
|validate|--project P [--strict]|只读；strict连警告都阻断|
|sync / build|--project P|generated；build另写单HTML与收据|
|status / budget / research-status|--project P|只读新鲜度、预算、统计|
|asset|--project P --file 本地图片 --metadata 说明.json --target place:ID或journal:ID|按内容摘要保存图片、绑定卡片；说明需caption/source/license；旧图不删|
|candidates|--project P --file candidates.json|候选登记，按id合并，不丢已有raw|
|screen|--project P --id ID --decision candidate或excluded --reason 理由|初筛状态；不冒充读完|
|source|--project P --file source.json [--refresh]|不可变原文及图片版本、registry指针；图片路径相对输入JSON目录|
|intake|--project P --file intake.json [--refresh]|人工正文文件＋按顺序的图片＋采集声明，原件可选保存在private；不执行归档网页、不联网|
|source-audit|--project P|只读原件/图文摘要和原文覆盖状态；完整声明不等于语义验收|
|archive-info|--file 保存的HTML|只读摘要、标题、可识别的公开来源和资源引用提示；不执行页面，不能证明离线可读|
|gallery|--project P --id ID|.runtime下正文全图单HTML供阅读|
|digest|--project P --file review.json|版本化消化记录与registry指针|
|routes|--project P --mode walking等|从默认时间线补相邻路线脚手架；模式需人/模型显式选择|
|route-info|--project P --id ID|只读URL和当前route/day哈希；含overview-ID|
|route-access|--project P|只读转场筛选、通道说明错误；错误退出1，待语义审阅不冒充已通过；见[通道核验](转场与通道核验.md)|
|capture|--project P --id ID --network [--allow-private] [--browser 可执行路径]|路线截图，reviewed=false；私址需要明确授权|
|route-review|--project P --id ID --file review.json|只有实际审阅后绑定输入/截图hash|
|weather|--project P --network|新天气快照及latest指针，独立失败单列|
|mcp-install|--network [--runtime 本机私密目录] [--tag 发布标签]|仅下载上游程序并记摘要，不启动|
|mcp-start|--network [--runtime R] [--port 18060] [--executable 绝对路径]|后台本机服务、鉴权、日志、连接记录；浏览器首次可需联网下载|
|mcp-login|--network [--runtime R] [--endpoint 本机URL]|本机二维码文件；扫码由人做|
|mcp-status|[--runtime R] [--endpoint 本机URL]|只读连接/登录状态，不回显身份|
|mcp-search|--project P --query 查询词 --network [--runtime R] [--endpoint URL]|只读平台搜索并本地登记|
|mcp-extract|--project P --query 查询词 --ids ID1,ID2 --network [--runtime R] [--endpoint URL] [--refresh]|只读平台详情；全部图片成功后导入原文；任一失败退出1|
|pack|--out 包外新目录|仅白名单工具包文件＋MANIFEST，不带运行态或旅行|
|release|[--out 目录] [--apply]|默认只读差异；apply生成快照，默认包内released，也支持同级输出；更新前核验原副本并保留旧版恢复点|
|verify-package|--root 已打包目录|按MANIFEST复核文件摘要|
|install-skill|--workspace 新宿主目录|自包含副本到宿主.agents/skills/travel-workflow，不覆盖|

联网参数表示使用者/调用者已确认所述范围，不赋予任意外发权限。地图命令只把指定节点发给Google，私址要另核--allow-private范围；不上传订单原件。

## 一批经验研究

默认按[人工采集与导入](人工采集与导入.md)取得有授权的资料，再gallery→实际阅读→Wiki→digest。下面是**可选MCP路径**，不需要每次研究都启动账号服务。

~~~sh
node scripts/travel.mjs mcp-status
node scripts/travel.mjs mcp-search --project "../my-trip" --query "目的地 秋季 咖啡" --network
node scripts/travel.mjs mcp-extract --project "../my-trip" --query "目的地 秋季 咖啡" --ids "精确笔记ID" --network
node scripts/travel.mjs gallery --project "../my-trip" --id "精确笔记ID"
~~~

模型实际阅读→写Wiki→按数据合同写review JSON→digest→research-status。禁止用脚本批量填read=true来代替读图。

## 检查与恢复

真实离线浏览器验收为独立命令：`node scripts/browser-smoke.mjs --project P [--browser 可执行路径]`，需先按快速开始安装可选Playwright。它会写`.runtime`验收报告与截图；不是`build`的隐式步骤。自动测试运行`node --test tests/*.test.mjs`，包级检查运行`node scripts/travel.mjs package-check`。

全量视觉清点：`node scripts/browser-audit.mjs --project P [--file build/index.html] [--browser 可执行路径]`。默认离线检查全部模块、每天六个阅读面、全部地点/Wiki弹窗，宽度1440/390/320；桌面和手机截图及联系表在项目`.runtime/visual-audit`，报告在`reports/visual-audit.json`。可用`TRAVEL_PLAYWRIGHT_MODULE`指定已有Playwright模块、`TRAVEL_BROWSER`指定浏览器；不自动安装、不联网。file必须是项目内相对路径，产物须匹配当前build回执。人工看图要求见[视觉巡检](视觉层级与全量巡检.md)。

validate输出的`valid`表示没有结构错误；`strict`表示是否启用了警告阻断，`passed`表示本次门禁通过与否。必须同时核对进程退出码，不能把strict时的valid=true当成通过。

validate错误必须修复；警告须实际审查，不能靠批量补hash消音。默认build允许未完成研究/缺截图，用明确空态显示；交付执行版时用validate --strict或逐条解释剩余警告。

source默认拒绝重复覆盖；--refresh创建新版本并让旧消化失效。天气失败不覆盖历史。pack目标存在拒绝。若派生文件生成中断，修正源后重新build，status验证最终收据；不用手改输出。详见[发布与隐私](发布与隐私.md)。
