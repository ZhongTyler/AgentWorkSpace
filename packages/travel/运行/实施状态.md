# 能力与验证范围

版本以 package.json 与 CLI VERSION 一致为准，包根是本目录。在宿主工作区中，`工作流/` 是唯一维护源，正式发布目标是 AgentWorkSpace 的 `packages/travel/`，由 `release-input/manifest.json` 白名单直接发布；不再维护同级 released。独立使用时 `release` 仍默认输出包内 released，pack 可导出到其他新目录。生成本地快照不是公开发布。

| 层 | 已有实现 | 边界 |
|---|---|---|
| 核心 | 初始化、事实与证据校验、研究导入消化、预算、路线指纹、天气快照、文档与离线网页生成 | 自动检查不证明语义声明或现场可执行 |
| 私人偏好 | 独立档案、显式选用、旅行采用快照；公开白名单隔离 | 不自动扫描或导入，不提供个性化评分器 |
| 页面 | 项目/地图双主入口，折叠时间线、吃饭、住宿、核对；全局模块导航直接展示，正式地图页保留；项目复用手册正文 | 便携版有基础数量和时间/订单关联；增强角色及条件计数仍按宿主接线 |
| 自定义前端 | 规范模板、机器组件合同、合成状态；frontend-build/check/audit 检查绑定、限制、新鲜度及离线多屏宽断言 | 当前适配自包含 HTML 模板；不自动迁移既有前端，不替代全部槽位覆盖审阅、对比度/键盘实测或用户认可 |
| 正文与证据 | fact/claim 引用、定域预约/价格线索、结论来源/范围/复查、同源 Markdown Wiki | 自然语言矛盾和来源是否真正支持结论仍需实际阅读 |
| 新使用者试用 | 冻结需求、白名单工作区、工程验收脚本和读者问题 | 不自动启动参与者，不把 Agent 模拟或作者自评写成真人验收 |
| 地图 | 精确地点、分段URL、截图、通道指引；浏览器会话内改起终点、增删重排并拆分导航链接 | 只是顺序示意和链接；原生交互地图未接入；国内跳高德、境外跳Google，不计算路网和ETA |
| 可选渠道 | 人工导入默认；MCP只在用户选择后启动 | 模拟测试不证明第三方平台真实登录可用 |

工程检查与声明边界见[发布与隐私](发布与隐私.md)。本地复盘不进入分发包；历史测试数字不冒充当前测试量。

新使用者试用目前仅验证了准备与工程检查工具，完整的新目的地独立试用未执行；是否启用由使用者决定，不作为本轮交付门槛。新增源码能力尚待正式发布时同步 AgentWorkSpace；只有发布包实际更新后，才复核个人网站的相关能力展示，不将本地版本写成已公开可用。

原创部分已获MIT发布授权；第三方内容保持各自许可，并按声明补陌生使用者和目标操作系统的实测。Windows自测、合成测试、真人旅行反馈、浏览器验收和线上部署分别报告。没有服务器也能完成离线交付。
