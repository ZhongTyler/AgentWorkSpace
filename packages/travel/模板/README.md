# 模板与启动

新旅行用init命令创建，见[快速开始](../运行/快速开始.md)。不要复制整套Markdown建立第二组事实源。

[项目](项目/)是需求、比较和讨论稿的内容清单。正式结构化字段进trip.json；总表、NOW、餐厅清单由sync生成。模板不与生成物并行维护。

|模板|用途|
|---|---|
|[主题Wiki](主题Wiki.md)|knowledge/按主题写；底部原文链接与阅读用途|
|[偏好记录](偏好记录.md)|机制与空白字段；实际档案放私有偏好目录，本次旅行保存采用快照|
|[来源记录](来源记录.md)|辅助整理官网；导入用[样例输入](../examples/source.json)|
|[研究覆盖](研究覆盖与消化记录.md)|明确问题；状态由registry及researchCoverage拥有|
|[方案比较](方案比较.md)|讨论稿；未采用不进入days|
|[预订前比较与预算](预订前比较与预算.md)|骨架与成本，合计用budget|
|[订单提取](订单提取.md)|原件在private，展示字段进orders|
|[地点卡与路线](地点卡与路线.md)|字段采集清单；编辑places/routes|
|[变更与验收](变更与验收.md)|实际检查与限制|

字段见[数据合同](../运行/数据合同.md)。占位行不是有效来源或订单。
