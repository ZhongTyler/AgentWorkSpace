# 研究工具与证据保存

Research 安装包是可升级的方法与工具模板，个人报告、采集材料及实际安装状态由使用者拥有。建议在包外研究目录采用下面分工；已有等价组织可复用，不强制改名或迁移历史。

| 内容 | 保存位置与要求 |
|---|---|
| 研究结论 | 用户研究目录的 docs 或同等主题目录；保留来源、事实/推断、适用条件与下一步 |
| 实测与可复核证据 | experiments 或同等新目录；保存方案、输入身份/许可、冻结基线、命令、原始输出、哈希和成本/未知项 |
| 工具维护材料 | integrations/<tool> 或同等维护目录；保存精确版本、依赖锁、许可、必要上游归档、使用/恢复说明与状态层级 |
| 实际运行依赖 | 包外 tools/runtime；忽略 node_modules、虚拟环境、模型和缓存，包升级不接管这些目录 |
| 账号与本机配置 | 使用客户端或系统保护的本机目录；凭据、Cookie、profile、配置备份不进 Git 或公开包 |
| 自用 skill | 保存可迁移维护源，明确安装到客户端发现目录；记录安装来源与本机定位，副本更新先检查已有 owner/改动 |

`.tmp` 用于短期探索；决定继续使用后转成固定且有版本的 runtime。迁移工具不改写历史试验的原路径/基线，而是新增迁移与当前连接记录。大输出压缩另存，日常读取摘要和针对性视图；不要把生成文件量当成研究价值。

区分“归档已保存”“工具已安装”“已注册”“握手通过”“当前客户端调用成功”“对本问题有增量”“已实际采用”。状态须有对应证据；未测的 token、金额、峰值内存或采用效果保持 unknown。只将有迁移价值、证据完整的材料交给已有 Knowledge 路径，安装工具不自动授权入库。

公开发布另走白名单和许可审阅：分发维护源、锁与必要归档，排除私人结论、实验内容、运行依赖、当前连接收据及账号。顶层工具归档不是完整离线镜像。Research 包升级/回滚只管理包文件；外部工具运行目录、客户端配置和用户研究资料需各自有恢复方式。

通用可复用实现归独立 Tools 维护，Skills 方法归独立 Skills 源；Research 不再成为全工作区工具安装的权威目录。旧 Research helper 是兼容入口。新安装通过 Tools prepare_home.py 建立包外版本化目录，显式安装与接线；升级保留旧 home，验证后切换，失败回原路径。私有迁移别名及原始连接收据不在公开包复刻。
