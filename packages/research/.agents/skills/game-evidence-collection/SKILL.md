# 游戏研究取证搜集

承接`research-collection`或宿主给的对象、缺口、材料与投入边界。返回可读原件及具体支持范围，不另开全作研究、来源库或Knowledge消化。通用技能不可用时也可完成已授权局部取材。

在接收方工作区定位Research当前研究／深拆合同、原游戏报告和信源管理；来源暂停、设备操作、资源owner及成本沿现行状态，不由本技能解除暂停。

## 定身份和路径

1. 区分作品／续作、平台、版本、模组、模式与观察条件。未知写unknown；解释固定源码可沿其版本，声称发行版行为需相应依据，不统一要求最高档同版互证。
2. 复用原报告的源码锁、发行物、规则账、媒体索引与缺口。先试通一个关键机制的“原件→规则／画面→可用证据”，媒体／操作接入未通前不规划长段实操；试通后仍覆盖原任务范围。
3. 按[游戏取证路线](references/game-evidence-routes.md)选最直接材料：源码固定提交；发行包先规则／配置／随包教程；否则用版本可辨的公开过程或实际操作。可以组合，不是三路必做。

## 获取与核验

- 官网／发行页先核主体和作品，再找手册、FAQ、补丁、开发日志和链接仓库／release。商店宣传、玩家Wiki、旧源码、现行包不混成同一事实。GameHOT提供候选，关键证据回原来源；来源不限于GameHOT。
- 源码／发行物保留版本、实际文件／素材身份及必要哈希，按缺口读依赖，不反复全库扫描。完整源码优先直接分析；发行物机制确有缺口才按可用`rea-investigate`和宿主REA合同定向查，不默认逆向或装工具。
- 组装可在游戏中成立的示范过程时，先核同一任务的可用对象、数量、装载及解锁条件。依赖源码解释位置或显示时间时，追到最终坐标、绘制筛选和刷新；中间记录的寿命只说明该记录仍存在。
- 媒体记作者、原URL、片段／帧、可见版本、剪辑与连续性，实际核前态→动作→反馈→后态及必要中间过程。视频帧／秒、模拟索引和面板计数分列；字幕、OCR、联系图只定位，不冒充看完、亲玩或听审。
- 操作／录制先核授权、目标窗口、短输入响应和解码，再扩大本批取证；保持用户窗口和录制范围。请求成功不等于角色响应。接入失败沿原工具停点和权限处理，其他公开材料路径继续；换输入／录制技术不由本页授权。
- 核规则与画面是否相容，补会改变判断的失败、替代条件或版本／装备改写者。声音无实际听音依据就留缺口，是否延期由原任务决定。

## 返回

沿原材料表交对象／版本、原链和文件、实际读取／观看／操作范围、可支持规则、冲突、未核项、下一动作及实际投入。跨版本互补不写成同版互证；素材齐全不等于机制解释完成。

主搜集层决定补取／结束，深拆宿主负责全作覆盖、机制分析、查证和审核。通用新源向原目录owner交候选，不自动订阅、购买、改频率、入库或恢复研究。
