# 游戏对象的获取路线

| 缺口 | 优先获取 | 边界 |
|---|---|---|
| 官网多入口／名称含混 | 核开发者／发行主体与作品，找规则、手册、FAQ、补丁、开发日志及直接仓库链接 | 沉淀定位思路，不写死站点布局；换域核归属，空搜索不表示无资料 |
| 已有官方／发行页面，外部视频接入不顺 | 先核页面已公开的原始截图、媒体链接或随包教程是否能补当前缺口，再扩外部来源；网页正文没列出媒体不等于没有原件 | 普通访问受阻不换路线绕验证；宣传片、剪切、淡出和抽帧不能自行证明失败回退或完整操作闭环 |
| 有源码，需规则／数值 | 固定commit和许可，按对象与依赖读原分支／执行原规则 | 固定提交不等于发行包；推演不替体验，原件未变不重新克隆全读 |
| 发行包可得，源码旧／缺失 | 固定包版本／哈希，优先内置规则、动作／配置、随包教程；有缺口再定向实现 | 资产声明、实际运行与旧源码分层；解析成功不等于运行，异常端点保留 |
| 有随包视频／原始过程 | 索引片段，核关键前后态和中间阶段，优先已有原片 | 录制构建未知照实记；视频帧不等于模拟步，静音不能证明声音 |
| 主要靠公开视频／截图 | 按机制、版本、模式和边界选过程，回解码画面／必要多图与GIF帧 | 高光不替完整循环，不拼多段为连续链；追原作者与转载底本 |
| 必须实操／录制 | 先核设备授权、目标窗口、短输入响应与录制播放，成功后只取必要情境 | 只录允许窗口；无效接入不反复吞搜集预算 |
| 设计意图／制作取舍 | 追实际作者原文、原访谈／演讲和迭代说明 | 意图、事实、推断和玩家效果分列；记者转述追原署名和上下文 |

## 已有案例可复用什么

对于按游戏帧轮询按下／释放的Canvas控件，先复用上一批同类入口已经成功的输入参数和状态证据。当前工具支持按住时，可用有界按住再释放做一次短测，并核实际画面变化；本轮HaxeFlixel例中160—250ms曾成功，具体时长随宿主验证。瞬时点击未响应时先辨输入是否被游戏捕获，再判断接入受阻或请求人工帮助。不能据一次无响应直接推广到所有输入通道。

- 2048：固定作者源码执行规则边界，另列有限网页观察；线上构建未匹配就不声称同版完整互证。
- Canabalt：固定移植源码／素材，结合作者原文和有限官方页操作；Flash说明、HTML5移植与当前运行分版本。
- FOOTSIES：作者规则＋1.5.0动作／配置及6段随包教程，旧源码补实现；面板、索引、视频帧分别核，实际输入先短测。
- Unsolicited：先固定作者HTML5、实际数据与原始表单图，验证一份完整投递和独立错误后再批量核表单族；颜色标记、字段语义及规则消费按本对象核对。方法与输入实例在当前Research根的`experiments/game-studies/unsolicited-sb05-20261106/README.md`，宿主安装副本沿Research定位提示查原记录。

这些案例支持所用路径，不证明所有游戏材料齐全或闭源大游戏成本稳定。具体文件与哈希留原档案，本技能不复制第二套证据库。

把找材料和打通接入分开观察，每次说明下一材料补哪项缺口。完整同版互证按实际结论需要加强；必要行为证据缺少仍要补，不能为控成本写成已覆盖。也不为每域相同媒体数量、全设备或最高档证明硬凑材料。
