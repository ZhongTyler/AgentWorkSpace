# 游戏研究成本与效果评价

在用户指定的包外批次目录维护本次用途、难度、质量底线、阶段投入和结果记录。已有cost日志沿原入口继续，按真实时间区间保留重复、等待、失败及未知，先核输入身份再复用旧证据。

本包自带[通用方法](../../.agents/skills/workflow-redesign/references/cost-and-effect.md)和[标准库计量脚本](../../.agents/skills/workflow-redesign/scripts/workflow_cost.py)，可先运行--help查看实际参数。开题、阶段检查、运行后复盘沿同一记录，依据原报告、审核和实际消费评价质量与使用效果。模板提供方法和合成测试，具体标准及投入由接收方决定。

历史研究正文和审核身份继续保留。模型、采集、Knowledge处理和项目采用沿当前授权与实际回执，节省效果按可比任务和同等质量判断。
