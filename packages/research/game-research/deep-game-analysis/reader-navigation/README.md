# 单份报告的目录与领域导航

正式交付仍是Knowledge/research-reports/<game>/reader/index.html一份离线HTML。悬浮覆盖与并排都保留，读者自行切换；没有已保存偏好时，840px以下默认覆盖并默认跳转后收起，但不禁止主动并排。并排侧栏宽度不超过300px或视口40%，收起后正文恢复全宽；切换和缩放保留读者选择及阅读位置。目录复用正文已有总—分—总目录，领域从本作研究盘点中按读者价值选择，沿原名称与顺序呈现。

`reader/navigation.json`保存该作人工编排的路线；它属于报告表达元数据。每步绑定原MD精确分节、文件/分节hash、图解或已排版正文落点、册内完整论证与阅读重点。跨域使用显式标related_section。主线仍负责完整解释；选读路线帮助定位，不删改研究、不代表已经读懂、不冒充另一份报告。

新报告可在manifest声明`reader_selection_version=1`，逐域明确`reader_visible`；排除项带`reader_reason`。后台domains仍覆盖完整基线，navigation.routes只对应选中的阅读领域。脚本检查选择、顺序及落点，实际读者价值由研究者和审计判断；旧报告不声明该版本时保持原导航。

## 制作与修订

先用human-research-expression确定章节与读者任务，所有新增人读文字同时用humanizer-zh与anti-defensive-writing完成一次主编辑。按同一问题排列必要前置、图解、具体过程、条件与回顾；一个原分节横跨多个图解时，把关键后续也列入路线。不要把一个宽泛图解挂给整章所有小节，或让顶部阅读重点承诺落点根本没有讲的内容。音频等延期域若没有有用分析，可从导航和正文省略，真实状态留后台记录。

杀戮尖塔、陷阵之志的已有人工计划由`compose_existing.py`生成；星之侵略者保留原已审路线。该脚本只编排这两个案例，不是对任意新游戏自动摘要或判断相关性的工具。新游戏从自己的盘点与文稿编排navigation.json，沿下面的构建与检查复用。

```text
python -B build.py <Knowledge/research-reports/game> --receipt <本批构建记录.json>
python -B check.py <Knowledge/research-reports/game> --output <本批静态核查.json>
```

构建基线须能追到已审Git提交或冻结原件，不只相信配置中的自报hash。build.py只加可剥离的导航层，拒绝未复核的原HTML或来源变动；去掉导航后须逐字节恢复已审HTML。重复运行应保持相同输出hash。正文发生变化时先审变化及相关路线，再更新base_html_sha256/来源身份，不能自动盖掉拒绝。

需要精确版本接受时，生成器显式固定文本换行，先核Git属性再计算身份；提交前比较实际暂存blob与已验证文件，尤其manifest、领域快照、正文、reader及原图。历史原件/收据保留原字节，不为统一换行改写；若只做序列化运输，保存前后语义等价证据，由原owner绑定新精确身份，不沿旧hash批准新文件。

## 分开核验

- 静态：与明确选中的阅读领域一致、每步源分节和正文标题对应、锚点/册内链接有效、原始标签无重复id属性且全页ID唯一、原场景/文稿/图片/脚本保全、资源自包含、无JS时原目录可用。先检查原始属性，再看解析树，避免解析器丢掉第二个属性而掩盖歧义。
- 内容：逐个去重分节回读，确认领域、source、target和focus一致；还要从该领域原范围查是否漏掉重要过程。hash和标题一致不能替代这一检查。跨图解补充、反例和延期入口尤其要看。
- 操作与视觉：在实际浏览器检查两模式、切换后的阅读位置、目录/领域页签、展开收起、前后步/退出/完整论证/返回、Tab/方向键/Esc、后退、窄屏和长标题/图片遮挡。至少用一次实际分栏宽度（例如900—1100px）点击并排并切回，不能只在宽屏看按钮或把默认模式当切换测试；确认收起恢复正文宽度、刷新复用偏好。不能用静态PASS或原报告的旧验收代替新增导航验证。工具拒绝访问时记录具体限制，不记为通过。
- 真实读者：用户反馈只支持实际读过的范围；未测理解与长期查找效果保持未知。

结构和语义变化分别复验，复用输入未变的事实审核。原型采用后旧样例跳回唯一正式入口，不继续保留第二份可修改人读报告。当前三作的检查与独立审计边界见[接收方入口](../README.md)。
