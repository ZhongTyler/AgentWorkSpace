# 像素资源制作

依据输入选择文字生成、参考图、透明图层、逐帧图集或既有骨骼模型路线。接收方已有的工具需要核对真实版本、支持格式与许可，再执行一个代表输入；预览、引擎播放和项目采用分别验收。

图集保留帧顺序、每帧时间、方向、画布、锚点与透明边。先验证目标尺寸中的轮廓、身份、接触位置和动作切换，再扩展动作。已有像素需保真时保存原图层，变换、补画与结构重建分别记录。

GLB先检查实际几何、骨骼、原生动作、morph、外部资源及来源许可。原生播放与跨骨架重定向分别选择，沿实际支持范围配置动作、循环、root职责、相机和方向。公开工具能力存在于接收方已配置版本时再调用，其他输入沿原引擎或编辑器流程处理。

原件、派生物和引擎导出都保留来源及许可。固定样本的技术结果按其样本范围使用，审图与实际采用由宿主负责。可发现的pixel-asset-production Skill提供进一步方法。
