# 本地素材制作与审阅

先明确用途、目标尺寸、风格参考、输入权利和接受条件，再查看接收方实际已配置的生成、加工及引擎能力。模型、服务、版本和运行环境由接收方选择和恢复，安装本包后按具体任务配置。

已有原图保持原字节并记录来源与许可。参考图按角色、服装、姿势、风格和构图分别标用途，记录消费顺序及实际送入范围。先在目标尺寸检查首样，再扩状态和动作；失败保留输入、参数、候选与恢复入口。

需要裁框、尺寸预览、状态组合时使用[资源审阅](resource-review.md)。需要像素角色、图层或既有GLB时使用[像素制作](pixel-asset-production.md)。外部编辑器、人工制作和已配置生成器均按同一来源、尺寸和引擎接受合同交付。

工具生成的候选经审阅后再接入宿主项目。真实调用、许可、画面质量、引擎验证和采用沿各自证据记录。
