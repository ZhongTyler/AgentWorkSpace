# 资源图册与采用前检查

资源图册是制作与采用之间的审阅产物。单体、图集、控件、状态皮肤和场景按本次需求集中展示，复用项目清单中的稳定ID、版本和来源。制作卡与图册链接保存在项目assets工作目录。

## 制作输入

先明确资源用途、真实显示尺寸、最小尺寸、透明要求和实际需要的状态。图集逐项绑定源图SHA256、完整物件裁框及安全边距。生成图板的行列只用于定位，实际切片根据可见主体核定。

每次候选变更建立新的工作版本，源图及此前失败保留。图标的绘画语言由项目规范拥有。切图、归一、抗锯齿缩放和原图编辑分别记录处理方法与输入输出哈希。

## 裁框与透明

检查全部受影响资源，尤其是分格边界、分离的尾迹/箭头/饰物与临近图形。主体应完整，透明区内应清除邻图残片。裁框贴到可见主体时回查原图，逐项修正。

用多个alpha阈值核对可见边界，并在深浅及实际底上查看。安全边距覆盖完整软边和阴影。完整铺底、允许出血的纹理明确标注边界策略。自动检查的阈值、拒绝条件和例外理由保存在制作记录。

## 尺寸与采样

独立资源按真实尺寸显示，覆盖本项目的最小、常规和放大检查尺寸。查看斜边、圆弧、细线、空洞、半透明轮廓、可见主体占比与相近图标的辨认。透明图使用支持预乘alpha的高质量采样，检查深底光边、断线及锯齿。像素资源沿其专属采样规格。

发现问题时先区分源图细节、裁框、过滤方式和实际显示尺寸。修正处理或图形后重看受影响项。把“可以解码”“边缘通过”“图形可辨”和制作人采用分别记录。

## 状态实际组合

用候选资源本身制作代表性的控件与场景组合。图标、底座、选中标记、禁用态、焦点、警示及Tips按实际兼容关系组合，覆盖当前需求清单。保留正常态作为对照。

状态映射表负责覆盖范围，每个要求审阅的状态还须有可见组合。完整画面检查信息层级、对齐、遮挡、贴底/滚动边界、透明及状态区分；九宫格或三段拉伸检查拼接缝、角部与徽记的形变。前景与装饰避让输入和必要信息。动态文字、数值、路径及标签由宿主规则或明确的展示夹具生成，指向与实际方向一致。

图册记录当前组合是资源静态预览、真实控件还是实际游戏状态，并绑定对应证据。引擎接入后的同状态同窗口比对继续沿原流程完成。

## 图册交付与审阅

图册至少提供以下实际入口。

- 独立资源及稳定ID，可查看和保存当前候选PNG。
- 按用途切换尺寸，深浅/实际底检查透明边界与轮廓。
- 可见的控件状态组合和必要完整画面。
- 本次检查、缺项和修正记录。
- 按资源/状态填写采用、需修改、否决及备注，并导出绑定输入版本的审阅意见。

图册采用内嵌图片或明确的本地服务交付方式。独立HTML需验证仅复制该文件后仍可加载全部图片及状态。显示真实加载成功数和失败信息，检查实际浏览入口。采用意见绑定ID、用途、源/加工版本和采用范围，再由宿主应用到清单和后续输出。

可复用[图册构建器](adapters/resource-review/README.md)输出独立PNG、尺寸版本和实际组合。宿主维护场景数据，构建器复用同一裁框与绘制入口生成图册和PNG。具体资源数、尺寸和游戏布局由项目决定。

## 验证范围

验证至少包含输入哈希、全部裁框的边界检查、实际尺寸、状态覆盖、离线加载及审阅意见导出。对本次真实失败增加能检出它的检查，例如旧裁框含邻图且触边时应拒绝。逐项可见检查与机器检查相互补充，工程结果按实际覆盖范围报告。


## 目录

无下级目录。

项目当前审阅统一进入[全资源图册](project-atlas.md)。历史批次保留，后续批次仅输出媒体及组合，由固定入口关联版本。

## 输入示例

复制templates/resource-review-manifest.json到用户项目，填写实际PNG路径、SHA256、完整裁框、分组和目标尺寸。源路径相对项目根，manifest也须位于项目内；需要透明边的资源保持边缘留白，满版背景使用edge_policy:full_bleed。输出选择新的批次目录，已有输出可保留为恢复与审阅证据。ID使用安全文件名，尺寸使用正整数像素。
