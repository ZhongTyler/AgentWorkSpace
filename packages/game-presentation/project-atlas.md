# 项目全资源图册

每项目以assets/index.html作为固定入口，需求、候选版本和审阅由项目catalog拥有，安装事实从实际receipt读取。通过本机服务写回JSON，按输入版本拒绝过期保存，未保存草稿与正式审阅分别处理。

可复用实现位于GameProject包的template/maintenance/scripts，包含asset-atlas.mjs、asset-atlas-store.mjs、test-asset-atlas.mjs及assets/index.html。初始化复制空数据模板，既有项目按维护层选择性升级。宿主模板实现为通用源，项目副本应随维护变更核对同步。

单体裁框、尺寸及状态组合沿[资源审阅](resource-review.md)。加工批次只输出资源及组合，使用resource-review构建器的--images-only，不为每批创建新的当前HTML。旧图册保留为历史证据。动态资源登记触发、阶段、时间、中断、同步与简化方式，逐帧/播放预览和引擎效果按各自证据判断。



## 目录

无下级目录。

页面需求按系统和具体页面登记到宿主atlas-pages.json，状态条件、控件适用和资源引用保持可追溯。图册交互复用非模态抽屉、按类型分组和三行平铺多选联合筛选。需求管理页仅管理尚无产出的条目，全部资源只读查看已有资源，审阅清单填写版本意见。页面作为资源类型保留系统/页面关联，每个一级分类标题旁可按二级用途分组。验收覆盖Markdown显示、图片直显、连续切换、取消和保存。

工作台自身的增删改沿宿主maintenance/workflows/workbench.md，维护职责、兼容、localhost自审及模板同步。

概览统计和进度跳转复用目标视图范围，清空旧筛选并验证内容变更后的刷新。未归属媒体按原路径与哈希登记归档索引，通过变更记录按需查阅。

资源身份、来源图板和组合用途沿模板assets/specs/atlas-audit.md梳理。独立登记核对脚本接入健康检查，覆盖来源、同哈希复用说明、非图像用途、原阶段状态依据及消费者/内容覆盖。图板与历史登记保留于变更记录，组件通过parent_ids查来源。
