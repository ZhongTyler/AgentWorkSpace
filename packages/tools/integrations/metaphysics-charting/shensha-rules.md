## 默认显示与按需查阅

这是面向本宿主子平研习和紫微恢复学习的界面优先级，不是现实预测效力结论，也不是宣布其他方法不用这些字段。

| 体系与字段 | 用途与处理 |
|---|---|
| 八字四柱、十神、藏干 | 常用，默认显示；每个天干/藏干十神可点开，显示本命日干、阴阳五行及具体关系，保留柱位 |
| 八字神煞 | 用户要求补入，默认显示，可单独关闭；仅12项且必须可见依据 |
| 干支五行 | 基础关系重要；配色与干支详情已有表达，不再重复一行 |
| 纳音 | 另有具体取法用途，默认收起；可选辅助字段或点干支查看 |
| 星运 | 日主对所查支的十二长生名，可辅助查阅；不能一项代替根气/旺衰判断，默认收起 |
| 本柱旬空 | 本柱所属旬的空支，不能混称所有柱均已经落入日旬空；默认收起，仍可查阅 |
| 紫微宫名、宫干支、身宫、主星与庙旺 | 识别位置、状态和会照，默认显示 |
| 紫微六吉六煞、禄存天马 | 对组合有实质用途，默认显示，修正过去把这些全部随辅杂曜隐藏的做法 |
| 本命及所选时间层四化 | 开关开启时显示；相关星曜不能被其他杂曜过滤隐藏 |
| 紫微其他杂曜、流曜杂项 | 默认收起，其他杂曜开关可恢复；全部本命星曜仍在宫详情 |
| 紫微大限年龄 | 大限层开启才逐宫显示，时间条始终保留完整区间 |
| 命主身主、长生、小限年龄、完整历法资料 | 仍可查，移到命盘/宫详情；五行局、农历日期与查看时间保留中心必要摘要 |
