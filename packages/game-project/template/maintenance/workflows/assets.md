# 资源操作入口

从配置 assets.directory 定位规划、catalog 和规格。新增先登记用途；修改建立新源/工作版本；退役先查引用与安装依赖。源与交付版本不原地覆盖，移动保全哈希和历史失败，旧制作卡改为路由。

通用合同由 assets.workflow_contract 定位；离线不可达时仍可保全/登记/检查，但停止发布，不猜测最新规则。当前本地检查支持清单、来源哈希、精确legacy和新工作台收据，receive/receive-generated→seal→publish复用可恢复事务；按通用合同操作，来源/采用绑定仍由维护显式编辑。

原画、地图棋子、头像按用途分ID和门；外部可商用不代替效果认可。实际安装从引擎receipt读取；catalog只写期望版本。源/完整提示/内部参考不能进入引擎或PCK；插件走工程流程。

变更后运行 health-check；保全/迁移不强制重跑游戏，交付引擎则验证实际资源、回退和包排除。未获效果认可不得标ready。
