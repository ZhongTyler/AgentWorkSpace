# 变更记录

## 2026-10-15 · v0.2.5反馈入口

- 观察、调节、复现或比较受阻时，路由feedback-loop或共用方法；复用既有工具，不预建平台。
- 只更新新项目模板；已建项目按宿主选择性采用，不改正式决定、参数或存档。

## 2026-10-14 · v0.2.4便携发布

- 补充独立副本与可选宿主边界；FromDemoToSpec 使用全称，不继承作者私人目录或权限。
- 保留空引擎、空资产与空决定接收状态；GameProject 新建器只复制已封存模板，不创建游戏、迁移旧项目或启用外部流程。

## 2026-09-20 · v0.2.3既有决定接收

- 新增空接收索引及maintenance流程，初始化/新功能讨论先消费原决定；延期≠未定、实现≠批准，局部例外与完整方向分开。
- 健康检查核对来源哈希、ID覆盖、处置及归属/替代引用，配套12项正反例。空模板保持无来源，不复制私人项目的产品决定；真实复用效果待观察。


## 2026-09-18 · 结构调整自动同步模板

- maintenance入口规定结构变更必须判断模板影响，需要时自动同步并验证；区分通用约定与项目专属内容，保留owner/冻结边界，不批量改其他项目。
