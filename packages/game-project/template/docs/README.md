# 项目文档

文档按它回答的问题分类。领域目录根部的业务文档默认是当前 SSOT；`draft/` 放候选材料，`archive/` 放已替代、取消或完成的历史。

## 目录

- [product/](product/README.md)：产品目标、体验、范围与玩法规则。
- [engineering/](engineering/README.md)：架构、技术设计、数据和运行边界。
- [delivery/](delivery/README.md)：路线图、里程碑、功能切片与交接。
- [validation/](validation/README.md)：验证计划、结果、验收与已知问题。
- [decisions/](decisions/README.md)：重要取舍及其替代关系。

一个事实只在一处成为权威：决定解释原因，验证记录证据，其他领域通过链接引用。
