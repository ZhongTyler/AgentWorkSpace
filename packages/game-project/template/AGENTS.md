# 项目协作入口

遵守当前用户授权与可达宿主的协作规则；不假设存在作者的 GameProjects、meta 或其他模块。没有宿主框架时，也须明确目标和范围，保护用户数据与其他负责人的改动，以实际文件和验证结果报告完成情况。

每次工作先阅读 [maintenance/README.md](maintenance/README.md)，识别操作类型、影响面、所需验证与收尾。产品认可、重要范围取舍和真人试玩结论仍由用户拥有；技术检查不替代这些决定。不把模板安装或结构检查当作授权外发、发布、迁移旧项目或覆盖既有决定。

当前文档和工程入口由 [README.md](README.md) 路由。项目正文与模板库分开维护；若宿主有 Git 合同，按其要求提交与闭合，没有专用合同也保留可定位基线和恢复方式。
