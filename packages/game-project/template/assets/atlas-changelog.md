# 图册功能变更

## 1.5.0 · 2026-11-08

制作进度合并为每行一个对应清单入口。来源图板和历史登记转入变更记录，组件可查来源及复用关系。补齐非图像用途、实现入口和原阶段采用依据，默认查看已交付版。全量登记语义与覆盖核对纳入健康检查。


## 1.4.0 · 2026-11-07

页签改名为全部资源和审阅清单。概览共用目标列表范围，制作进度按已有资源与未产出需求分列，跳转清空旧筛选。保存、聚焦与定时刷新后同步概览。未归属媒体登记归档索引，变更记录提供按需搜索和分批预览。


## 1.3.0 · 2026-11-07

页面状态并入页面类型，保留系统/页面关系。资源库只读查看媒体和规格，审阅工作台专用版本意见填写，需求管理页管理尚无产出的需求。登记产出后自动转入资源库，Agent复用同一API与并发校验。


## 1.2.0 · 2026-11-07

合并需求工作台到资源库，新增需求与规格编辑保留在资源库内。类型、制作进度、工程状态改为搜索栏下方三行平铺多选，修正复选框尺寸。资源库与审阅工作台每个一级类型标题旁增加按二级分类开关，支持用途细分及旧数据推导。



## 1.1.0 · 2026-11-07

变更记录按Markdown显示。资源库、需求和审阅支持组内多选、组间联合筛选，并按类型分组。需求视图突出规格与优先级，资源视图突出媒体和版本。全部详情使用非模态右侧抽屉，可连续切换、Escape或点击空白关闭。版本及证据中的图片直接预览。

页面需求由atlas-pages.json按系统/页面登记，包含条件组合、关联状态、控件适用关系及资源引用。健康检查核对全部关系。

## 1.0.0 · 2026-11-06

固定项目入口，接入资源类型、用途、制作进度和工程安装视图。需求、新版本与审阅按输入版本写入清单，保留历史意见。提供完整比例预览、版本对比、动画逐帧、声音/视频播放、状态组合及文件归属核对。
