# GameProject 使用与维护

这是可选的 Godot 项目工作区模板库，遵守当前用户授权与宿主规则。新项目通过 scripts/create-project.py 先预览、再显式应用到不存在的包外目录；项目事实、素材、引擎和构建在用户副本维护。不得修改发布模板代替业务项目，也不得用创建器覆盖或自动迁移已有项目。

已有项目先审阅职责、目录、事实与决定归属、工程位置、资源合同及恢复方式，再提出选择性吸收、并存或保持原样的方案。目录名称与健康检查不证明流程兼容。缺少其他包不阻断基本维护；可选支持按实际已安装入口和接口定位。

模板正文在来源仓维护，按白名单发布。通用改善经审阅后回来源，不复制游戏专属决定、素材、状态、账号或构建。模板/包升级与用户项目选择性升级分开；工程检查不是已创建引擎、接收认可、游戏品质或真实试玩通过。
