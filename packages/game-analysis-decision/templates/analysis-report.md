# 分析结果

先回答问题，给出结论及成立范围。

说明真正支撑结论的事实、计算或来源，连接“观察 → 解释 → 推荐”；必要时指出最强的其他解释和可区分证据。局部观察、仿真、来源描述与真人体验明确区分。

复杂结论可用简短表格比较，但不为了完整性展开所有领域。来源行内引用即可；只有独立复用时建立 EvidencePacket。

最后说明下一行动和会改变判断的未知。已有授权内能完成的验证先执行再报告；未做的列为未做。普通分析由 Agent 直接消费，不新增人工签字。

后续真实结果到来时在宿主原记录回看预期与实际、实际使用内容及成本；归因和维护入口按[学习协议](../protocols/learning.md#从真实结果回看)，没有新结果不新增空记录。
