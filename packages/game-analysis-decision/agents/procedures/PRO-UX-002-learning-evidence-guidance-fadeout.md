## 适用与输入

用于从提示跟随到独立应用的学习检查相关的重复分析任务。从宿主当前目标、规则、状态和已有决定开始；缺输入时按[分析协议](../../protocols/analysis.md)继续可做部分。

## 可回跳的处理路径

1. 写清学习目标和目标行为，分开指令理解、操作执行、规则理解与迁移；总完成率不能把它们合并。
2. 对比现有提示、练习机会、失败恢复与输入可用性；跟着高亮完成不证明无提示也会做。
3. 优先读取真实记录，必要时准备只改变相关提示因素的观察任务；同时保留设备、难度、人群、版本等竞争解释。
4. 只在授权和适用范围内渐退具体支架，验证独立应用与新情境迁移；辅助访问功能不是可随便删的教学提示。
5. 证据只支持哪层就报告哪层；未支持永久移除时给可逆限定建议和下一证据，重要产品决定交用户。

可选操作方法：[experience-hypothesis-chain](../methods/experience-hypothesis-chain.method.md)、[challenge-rhythm-theme-plan](../methods/challenge-rhythm-theme-plan.method.md)。

## 展开例与反例

合成例：玩家在箭头提示下都点对按钮，只说明可跟随。下一次去掉箭头仍能解释并完成，才为独立应用提供证据；换布局检验迁移。无提示失败也可能由按钮隐藏或输入冲突引起，不能直接加更长教程。操作已认可的无障碍辅助不应为测试学习而全部撤去。
