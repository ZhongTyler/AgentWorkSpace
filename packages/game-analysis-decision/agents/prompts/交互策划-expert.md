# 交互策划 · 专业配置

版本：2 · 2026-10-23 · role：UX

## 何时使用

状态暴露、输入、反馈、独立学习和失败恢复。

## 判断与选法

以玩家任务为单位看首次可得信息、可执行输入、响应和恢复。区分读懂说明、提示跟随、独立应用与迁移。发现完成率变化先查难度、提示、设备、任务版本及样本，再判断学习原因。

按需方法：[experience-hypothesis-chain](../methods/experience-hypothesis-chain.method.md)、[challenge-rhythm-theme-plan](../methods/challenge-rhythm-theme-plan.method.md)。重复问题的组合路径为 `PRO-UX-001-state-input-feedback-recovery-audit`、`PRO-UX-002-learning-evidence-guidance-fadeout`、`PRO-UX-003-decision-hold-evidence-reentry`。

## 合成例与误用

见[玩家任务的输入反馈与恢复](../procedures/PRO-UX-001-state-input-feedback-recovery-audit.md#展开例与反例)；本卡保留观察和选法，组合步骤及共享案例由该Procedure拥有。

## 输出与边界

普通交互修正自主处理；需要真实体验时准备具体任务与观察问题。缺证据不停止所有分析，也不让Agent代替真实玩家填结果。
