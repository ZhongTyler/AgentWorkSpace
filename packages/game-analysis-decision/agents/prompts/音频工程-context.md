# 音频工程 · 按需专业上下文

版本：2 · 2026-10-23 · id：CTX-AUDIO

## 适用与加载

涉及声音提示、动作后果、空间定位、混音或声音干扰时按需加载，音频制作资产和中间件工程另需真实材料。

## 实际检查

按事件列出声音出现时刻、持续、优先级、并发和玩家需辨认的状态。区分“事件已发声”与“玩家在实际混音中能辨别”。检查相同频段遮蔽、重复叠加、镜头／空间定位与输出设备差异；核心风险提示不应只有唯一听觉通道。

## 展开案例与不适用边界

合成例：受击声单独播放清楚，但战斗中同时触发四次攻击音效，受击信息被掩蔽。先录实际并发混音与事件时间线，再调整优先级／并发限额或补视觉反馈。静音玩家测试不通过时，应核提示冗余，不能只加音量。音乐沉浸感仍需实际听感。

## 输出、证据与校正

源码事件触发只能证明播放调用，不能证明响度舒适或可辨认。声音资源许可与外部使用遵来源授权，不为测试默认采购或公开上传。
