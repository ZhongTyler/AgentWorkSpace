# 可复用分析操作

这里保存现行Method，负责“怎样做一项分析操作”；不充当专家身份或整类问题流程。使用时只读匹配的方法，展开案例可用于理解，不能冒充实际效果。

新版导航与运行资格由[能力目录](../catalogue.json)及learning/state.json（存在时）提供；[registry](registry.md)保留稳定ID与旧客户端状态。每张Method的candidate仅表明未声称旧ready；实际限定采用、范围与撤回经[学习协议](../../protocols/learning.md)和learning-cli处理，不再要求每次收据、固定两个项目及逐卡人工签字。

| 方法 | 主要解决的问题 |
|---|---|
| [体验命题链](experience-hypothesis-chain.method.md) | 目标、规则、反馈和玩家判断之间的可检验关系 |
| [因果约束图](causal-system-map.method.md) | 资源／状态关系、共享容量和竞争解释 |
| [分层平衡矩阵](balance-matrix-review.method.md) | 加权样本、局部压制和版本／选择混杂 |
| [挑战节奏规划](challenge-rhythm-theme-plan.method.md) | 可见与可行动窗口、路线、学习迁移和恢复 |
| [逆序交付计划](reverse-milestone-plan.method.md) | 可验收完成、关键路径、资源和范围取舍 |
| [同盘价值比较](paired-state-value-comparison.method.md) | 机制与合法替代的局部收益、个人资源、阶段后果和换阵机会成本 |

数学部分可用scripts/analysis-math.mjs复算，输入单位和假设必须一致。工具PASS不证明方法总体有效。来源使用稳定Knowledge标识，解析只读原材料后仍需检查是否支持主张。新方法按[模板](method-card.template.md)编写必要内容，不要求填满所有小节，更不强制成长为Procedure。
