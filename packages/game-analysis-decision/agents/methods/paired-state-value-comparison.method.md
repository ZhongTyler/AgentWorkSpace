## 何时用／何时不用

机制已经实现却不知是否值得使用；新能力、换人或成长看似有效，但可能被直接行动、既有构筑或阶段结算取代。至少取得可复现状态、真实规则与两个合法计划。只检查按钮可用、公式正确或单一常量时，用更简单的规则检查。

本方法比较局部替代行动；系统因果图负责跨系统关系，分层平衡矩阵负责群体／阶段分布。局部结果不能替代后二者，更不能独自支撑重要决定。

## 可执行操作

1. 固定问题与共同起点：规则／内容版本、盘面、库存／构筑、个人资源、共用额度、敌方意图、待出生状态和必要随机流。相同seed但配置／随机命名空间改变，不算同盘；无法冻结时说明混杂。
2. 给出使用机制的计划和最强已知合法替代，必要时保留不行动。找不到替代不等于不存在。换阵须支付换出角色、装备重分配和额度的机会成本，不能为新阵容重抽题。
3. 执行到会改变判断的共同阶段：技能末清理、敌方行动、出生和必要的队友后继。记录即时与阶段后结果、目标组成、个人AP／MP／HP、共享资源和剩余威胁；动画、事件次数和立即收容数不能代替结果。
4. 逐项解释差异。声称节约资源有价值时，给出节约后实际可做的事；将刷新／无法转交的剩余资源不能自动算收益。固定计划被拒绝只说明该计划受限，不证明所有替代都不可行。
5. 保留正例、替代同样有效和机制冗余的反例，再检查正常供给与常见状态是否能遇到这些机会。人工特制题和有限策略不能证明发生率、最优解或玩家愿意使用。

输出只保留能改变下一行动的比较：局部条件、代价与结果、最强已知替代、未搜索范围，以及应改机制、内容、供给还是反馈的条件。已有证据支持下一可逆动作，或剩余问题需要真实UI／Play时停止；不追求固定施放率。

## 展开例与误用

合成例：同一盘面，甲用4AP直接处理一个目标；乙用1AP搬开遮挡后，甲仍花4AP却能处理两个。可说额外支付乙1AP换来了一个目标的局部结果。若甲已有贯穿、不搬也能处理两个，则搬运冗余。若提前清除目标释放下一批出生，须观察阶段后状态，不能只以即时处理数称更安全。

回顾式提取：真实项目记录展示过清射路的个人资源价值、直接击杀同样有效、贯穿使搬运冗余，以及提前清敌改变pending出生的反例。这支持本卡值得候选试用；未做本卡引入前后的独立效果对照，不宣称方法已提升质量。
