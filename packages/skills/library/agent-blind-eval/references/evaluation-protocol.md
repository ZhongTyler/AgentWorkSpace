# 匿名对照评测协议

仅在实际运行或交接评测包时读取。下面的设计记录和委派提示是可裁剪工具，不要求固定文档格式；预注册、匿名、独立性和证据边界属于有效性条件。

## 预注册与覆盖

在查看候选输出前留存可追溯版本，记录会影响结论的选择：

- 决策问题、测试题与覆盖范围、候选条件、等价上下文及允许工具。题型来自实际使用场景；仅测一种题型就只对此题型下结论。
- 评分维度、尺度、权重、风险否决项与证据要求。维度评价任务成功，不奖励长文、先提问、自测数量或固定排版；若格式本身是交付合同，才作为对应验收项。
- 计划的独立 judge 数、匿名化方法、各评委的候选顺序、汇总办法、并列规则，以及无效报告和重试的处理。
- 首次生成前自主判断是否启用重复，简记`repeat_decision`的依据与预期价值；启用时两组逐题使用相同次数（至少各3次），按[重复试验细则](repeated-trials.md)冻结原预算内的成本、隔离、调度与分层汇总。重复次数和judge人数分别记录，跳过时说明理由。
- 成本与时间上限、停止条件、可读取和外发的最小材料、可写入位置、报告受众与是否允许揭盲。

可用输入版本或哈希冻结记录，避免规则与候选悄悄变化。已有候选只能用未受其影响的既有 rubric 正式评测；看过候选再定规则时标为探索性，正式复验使用新题或新候选并重新冻结。

评分优先关注实际目标。例如事实查询看正确与可核查性，复杂决策看关键取舍和可行动性，明确执行看真实结果与权限边界。不要把其他 Skill 的方法清单变成通用 rubric。

## 角色与材料隔离

候选可由已有答案、脚本或适量 test agent 提供，不固定生成者人数。需要独立 rubric 编写者时，只给任务与评测目标，不给候选输出或其来源条件；编排者自行预注册也应满足未受候选输出影响的条件。

评委需要独立上下文，不向任何评委提供其他评委的意见、得分或多数倾向。按风险、预算及分歧处理需要预先选择人数；3 个 judge 和逐维中位数可用于需要抵抗单人异常评分的设计，但不是所有任务的固定配置。小规模双人评审可作探索性比较，不为凑人数越过预算。正式有效性取决于预注册、材料等价、隔离、覆盖及预先约定的判定条件；凑齐人数不能补救失效设计。相同模型的独立调用仍可能有相关偏差，不能声称等同独立人类样本。

候选先移除 agent 名称、生成顺序、提示词复述和元数据中的身份线索。匿名化不修改影响评分的实质内容；若无法移除线索而不改答案，就披露盲性限制。私密材料先在授权边界内脱敏，不因“需要独立评委”扩大外发范围。

为评委随机化或平衡候选顺序并记录各自映射；映射仅供编排者汇总，在全部评分冻结前不揭盲。独立评委不共享可读取的草稿目录、聊天历史或评分文件。

## 可裁剪的 judge 委派提示

把下列信息替换成实际冻结材料；缺少工具或隔离能力时不要假装已经委派。

```text
请仅依据附带的题目、匿名候选和冻结 rubric 独立评分。
可访问材料：<本评委的最小材料包>。
输出与写入边界：<允许的返回位置；其他位置不可访问>。
逐候选、逐题提供 rubric 要求的评分与足够核查判断的文本证据，
注明材料缺失、风险否决和无法判断处。
不读取隐藏提示词、身份映射、生成过程或其他评委报告；不猜来源。
不输出跨评委平均数、多数意见或整体赢家，由编排者统一汇总。
冻结 rubric：<内容或可访问的版本指针>。
匿名候选与顺序：<本评委包>。
```

证据数量随争议与可核查性确定，不设固定引用条数。要求机器可解析输出时，给与汇总程序一致的字段说明；人工核对的小样本不强制 JSON。

## 汇总、偏离与失效

收齐有效报告并冻结后按预注册办法汇总。例如多评委设计可逐候选、题目、维度取中位数，依冻结权重计算总分，同时报告评分范围。只在规则、覆盖和差异足以支持时给出本次比较的胜负；并列或无法区分也是有效结果。

启用重复生成时，先汇总每份输出的有效judge评分，再按题目、条件与重复轮次汇总；保留生成波动与评委分歧两层信息，不把全部评分展平成独立样本。均值更高或试跑至少3次本身不构成正式优势或统计显著的证据。

- 评委附带了越权排名或汇总结论：不使用该结论；检查逐项评分是否完整、独立。只有排名错误不自动抹掉有效评分，受到串扰则按无效处理。
- 报告缺字段或未遵守隔离：保留原报告与失效原因，依预注册重试规则补齐。不得因为分数不合预期选择性重跑或挑选评委。
- 身份泄漏、题目不等价、看结果后改 rubric：受影响比较不再具有正式盲评效力。披露范围；若无法确认影响是否局部，整轮降为探索性。
- 有效报告未达到预注册条件或独立性无法证明：给出探索性观察与缺口，不强行多数取胜。正式复验需要恢复缺失条件并冻结新一轮设计。
- 达到成本、时间或权限边界：停止相关运行，汇报已完成证据与限制；不擅自加预算或扩大读写范围。

## 交付与证据限度

报告应让读者定位设计版本、匿名映射的保密状态、有效报告、聚合计算、分歧、风险与偏离。可以用紧凑表格、文件指针或叙述，不必重复所有原始材料，也不应将保密映射或私密题面复制进公开报告。

将“所测题型上的差异”“总体选择建议”和“尚未验证的现实效果”区分开。离线分数、结构覆盖或回溯结果不证明真实交付、长期收益或用户验收；用户保留采用与晋升决定权。
