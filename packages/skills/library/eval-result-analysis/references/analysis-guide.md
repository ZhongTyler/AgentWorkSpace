# 细分与重复口径

## 语义与事实

先抽取预测，再关联事实；执行者已知答案时保留该限制。每个可核单元至少记录：原始ID/定位、原文及条件、主预测/替代/附加/边界、任务维度、精细度、置信度、事实ID、事实来源层级、符合/不符/部分/未知及理由。

从两个层次处理复合文本：把主选择拆成角色、行业、档位、年份等可核组件；逐段检查具体表现，确有多个可分判断时拆成组件。段落数不等于独立原子事实数。部分符合写出哪些组件，避免统一折半或用泛泛相容性抬高整份准确率。条件等于结果的假说只提供核验线索。

同时给已核范围与未知范围。主预测精度、备选覆盖、宽泛组件相似、建议质量分列；同一事实重复出现去重。未知不作错误，也不作正确。标签只记一个职业时，不能据此否定副业、股权或其他未记载经历；并集标签保留并集。题目给出的事件类型不再算预测增益，理论上“适合”不转换为真实“从事”。

真值来源可信度与输出预测置信度分别记录；内部逻辑或引文通过不等于现实有效。未做独立复标时，以原文和理由支持人工复核，不声称标注者一致性已验证。

## 计算

可选脚本仅处理两个条件、选择题概率矩阵，Node.js 22+。它不推断标签、语义、失败状态或预算，使用者从原合同提供有效原稿，缺失位置保留在另一张计划/状态表。全样本、按题等权及共同完整子集分别看，脚本输出的总体统计是有效行的合并描述。

```json
{
  "conditions": ["A", "B"],
  "planned_repeats": 3,
  "records": [{
    "case": "Q1", "condition": "A", "repeat": 1,
    "alias": "N01", "system": "main", "dimension": "career",
    "choice": "a", "answer": "b",
    "probabilities": {"a": 0.6, "b": 0.4},
    "confidence": {"trend": "low", "manifestation": "low", "timing": "unknown"}
  }]
}
```

`case × condition × repeat × system`唯一；两个条件的case/system/repeat含义一致。概率有限、非负、和为1，choice/answer均在选项中。脚本只支持恰好两个条件；输入为至少一条有效记录，planned_repeats为正整数。不同题或体系的选项数量可不同。

```text
node scripts/analyze-records.mjs input.json statistics.json
node scripts/check.mjs
```

- Brier为各选项`(概率−真实指示值)^2`之和再取均值，越低越好；均匀分布参考依选项数变化，四选一为0.75。没有完整概率就不填造完整计划的Brier。
- Top-k遇第k位并列，分别报告保证进入与可能进入的数量；用全部允许集合比较候选稳定性，或将并列组标为不确定，避免按字母打破并列。
- 重复分布、两两选择一致率及概率TV分别计算；TV为各选项概率差绝对值和的一半。仅一次时两两统计为unknown。三次首选相同并不证明理由、条件也相同，语义复查仍需原文。
- 配对以原同题同重复为准，先求题内A−B，再题等权；逐一去题检查是否由一题支撑全部优势。方差、标准差、范围只描述已观察波动，不是置信区间。
- 高把握、低间距等探索阈值在该轮细分前写清。声明等级全相同时，它不能用于区分能力；概率校准需要更大且独立的样本。
- 缺失分别列业务失败、基础设施无效、没成稿、未知原因。最好/最坏界限不代替原分数，不为缺失补概率。保留被拦截的原稿，报告级可交付与单条判断保留数量分别显示。

## 分析后的复查

用可手算的合成数据检查并列、漏配、重复ID、失效概率和原稿/交付差异，再复算真实数据关键计数。脚本通过仅证明计算行为，不证明标签与语义正确。

复查常见遗漏：

- 历史行业被当成现职，题目提供的信息被当成预测。
- 列出多个互斥可能后，把任一接近真相计为主判断命中。
- 把“可能较好”按“准确识别最高点”评分，或用某年最高否定其他年收入不错。
- 实际评审来自独立文件，却读取了首稿里尚未评审的占位字段。
- 初判与终稿只改解释，就宣称纠错增益；修订后结果冒充首稿结果。
- 作者开始、首次读取、编译、交付使用不同计时起点却放在同列比较。
- 复核通过的百分比替代现实准确率；重复、体系或句子数扩充独立样本。
- 额外匿名化、补读、失败投入遗漏；字符误换算为费用。

补充分析优先解决已发现缺漏。多数投票、概率平均和两体系融合只是新的事后策略；若准备采用，再用冻结规则和未见题验证。按各因素同时变化的程度收窄因果结论。
