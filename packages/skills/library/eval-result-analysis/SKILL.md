# 已有评测的多维分析

把留存输出转为可追溯的能力边界与改进顺序。主要结论回答：什么任务较好、什么会稳定地错、差异由哪些题支撑、花费换来了什么。沿用原评分；新增口径标明事后探索。

## 先确定能回答什么

核对题目、条件、重复、体系/子任务、原稿、最终稿、失败、评审和消耗记录。选定实际独立单位，建立每个计划位置的去向；重复、评委或段落数只增加测量，不增加独立题目/人的数量。

保全输入哈希及原计分。核对标签与题面文字的对应，尤其重排选项；确认“真实反馈”是独立现实资料、作者自述、题库答案还是理论答案。给出相应可信边界。已看过答案的标注如实写为知情事后分析。

完成本步时，每个位置都能追溯到原始输出/缺失原因，标签层级与可核实范围明确。数据缺失阻断相应结论，其他分析继续。

## 分层分析

选择能改变判断的维度，结合任务而非凑指标：

- **能力边界**：先按任务内容，再按方向、具体表现、精确端点分层。细分样本数随结果显示。复合答案、条件分支或现实反馈不完整时，读[细分与重复口径](references/analysis-guide.md#语义与事实)。
- **稳定性**：有独立重复时比较同题同条件的选择、概率、意义、依据和条件，分清稳定正确、稳定错误与摇摆；只重复评分同一稿时，分析的是评分分歧。缺次数的组单列。
- **方案差异**：沿原配对比较，再按题汇总；展示原稿及交付口径、共同完整子集、逐一去题和差异集中度。两项同时变化时只解释整套方案，单因素贡献保持未知。
- **置信与排序**：有概率时看正确项名次、Top-k并列区间、Brier及高把握错误；有等级时检查等级是否实际区分对错。小样本只作描述，避免把主观概率包装成已校准频率。
- **过程与成本**：区分计算/来源忠实/内部一致/现实正确。对照封存的初判与终稿找实际变化；纳入查阅、复核、失败、返修及共同投入。字符、token、费用各用实际单位，缺失保持未知。

选择题概率数据可使用[scripts/analyze-records.mjs](scripts/analyze-records.mjs)，输入合同与公式见[计算口径](references/analysis-guide.md#计算)。其他任务直接适配原有评分表，不为运行脚本虚构概率。

## 复查后再补充

第一版形成后回到原文核对：分母/缺失、标签映射、复合与备选、未知、并列、时间口径、重复独立性、被过滤稿件、共享成本及因果归因。机械复算与语义复查分别记录；同一执行者复查不称独立评审。

保留第一版。新增必要分析另列，并说明解决哪个缺漏；例如多数投票、概率平均、缺失最好/最坏界限和跨体系互补，只作为事后诊断。知道真相后挑“任一正确”的结果是理想上限，不是可执行策略。

停止在证据能支持的位置：没有现实真值的维度列缺口，不补准确率；修订评分后不能回称预注册判胜。需要新题、独立评委或新生成才能解决的事项，交付最小后续设计，执行权限沿用户原授权。

## 交付与验收

交付可读报告、逐题对照、带原文定位的错误/组件标注、可复算统计及分析复盘。按“观察事实→可保留解释→替代原因→改进与下一验证”组织，区分原结论与补充结论。

关键数字能回到原记录；未知与失败可见；结论未越过独立样本和真值覆盖；每项优先改进都有具体错误证据。交付前润色已有文字时保留数量、限定和状态。方法验证不自动改变被测流程或发布能力。
