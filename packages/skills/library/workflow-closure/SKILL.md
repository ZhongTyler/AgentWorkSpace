# 工作流收尾

先定位宿主 README/AGENTS/COMMAND_MANUAL 或等价完成合同。已有明确要求按其执行；没有专用合同也能完成用户授权的收尾，不凭本 Skill 额外要求 W0–W3、固定 trailer、评审或工具。授权不因 Skill 扩大。

核对本轮范围、实际 owner、已有 dirty/index 与验证结果。只提交本任务文件，保留其他人的工作；按风险检查受影响行为并读取真实退出码。未执行、失败、工程验证与人工接受分开报告。只更新因本次结果失真的权威状态，不机械改所有导航。

涉及异步构建、部署或后台服务时，用必要的提交／产物版本、任务ID或实例标识核对本次对象，再有界等待终态并验证实际结果。启动成功、最近一次成功或旧进程不能代替本次完成；超时保留未知、停点与恢复入口。输入未变且仍覆盖目标的有效证据可复用。

涉及子仓时，每一级直接父仓都必须提交匹配子结果的 gitlink，核对实际提交树；只暂存指针或只提交子仓不能说已闭合。宿主已有检查器时使用并回读实际提交消息；没有时核对真实 Git 证据，不声称机器检查通过。push、发布和删除须有相应授权。

暂停交接保留范围、当前结果、失败证据、恢复入口和下一动作，不把 checkpoint 当完成。完成报告覆盖实现、验证、Git、发布与仍需真实用户验收的部分。
