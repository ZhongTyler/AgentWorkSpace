# 经历到机会

按[七步流程](references/opportunity-flow.md)复用用户已经提供的经历、成果和约束，连续推进可完成步骤，只询问阻断下一判断的缺口。记录继续沿当前会话或接收方指定的位置。

本方法可独立执行。已有LifeDesign或等效模块时复用它的输入与记录，缺失时使用本包流程。安装后由真实任务触发，市场信息按当前来源核验，收入与能力依据保持可追溯。实际调查、外发和商业行动沿用户授权。
