# 完整版研究如何交付

先列原研究的认识、案例链、关键数据、反例、条件与未知，逐项对应完整版的图、局部说明或可读补证。记录“已解释”“重复认识合并到哪里”“册内补证”“经用户允许暂缓／不适用”。重要反例与适用条件在相关解释旁；单纯给MD链接不能算承接。

完整性按意义核对，不要求把全部原文铺进正文。2026-10-27《杀戮尖塔》148页版虽然逐字符承接，用户实际反馈仍像MD堆、难读；该制作检查只能证明原文保存，不能作为完整版表达的充分标准。文字多时先重新编解释，不只加图片、缩字号或折叠长段。图解方法见visual-explanation；保留精确短文，不把“尽量视觉解释”推广成任何内容都禁用文字。

完整不等于原研究已经穷尽游戏或问题。材料本来的partial、版本/mod、抽样、规则说明、条件推演、真人体验与未验证部分继续保留。正文可以重新组织，但不能用新目录、润色或渲染宣布旧缺口已填。

人读稿是面向读者的维护副本，原档案拥有事实。所有表达优先使用可用的humanizer-zh检查冗余、歧义和句子衔接，保留数字/限定与原作者归因；代码、URL、ID、表格原始数据不机械改写。清楚的段落可以保留，润色不是摘要许可。改写后做source-fidelity对照，覆盖记录和字数只作定位线索，不替代语义检查。

正文、案例、来源说明先在完整版内部互链；工程和验证历史可放明示时点的附录。原件索引服务核底本与恢复，不打断常规阅读。不重新把所有文件平铺成一套需要读者自行拼装的目录。

用户要一份产出时，图解正文与详细论证属于同一报告。正文先让人理解机制和发现，附录承接完整过程、计算、案例、证据与明示时点的历史；总目录能定位两层，查看依据后能返回原阅读位置。不要把旧文字版挂在“详细依据”下，让读者在两份各称完整的报告之间切换。旧版保留为历史文件，当前阅读不依赖它；格式只制作本次选择的HTML或其他载体。

已有已审`render_visual.py`与`render_book.py`输出时，`scripts/assemble_html.py manifest.json --out reader`可复用原图解主线并将全部详细文稿排入附录。manifest含visual_html、detail_html、story、book的实际路径，inputs固定这四个文件的SHA-256，appendices按id/title/intro/documents声明分组；可用edition、introduction指定合并后的版本说明与读者导语，不绑定某次案例的路径或文案。全部详细文稿必须恰好归属一次；链接转为同页锚点，图片内嵌，单独交付index.html即可阅读。它不重新摘要，也不生成PDF；不支持任意网页，输入布局改变时须重新核验适配。旧页面是制作输入，不是最终阅读依赖。

合并后对照全部文稿的正文、表格、图像与原锚点，检查没有内容丢失或同名ID；实测图解→附录→来源→返回原位置，以及键盘、窄屏、看图关闭和离线使用。不能仅以合到同一个文件就宣布成为易懂的完整报告。

## 可复用的完整文稿辅助

需要全文排版底本时，可用scripts/parse_markdown.mjs和scripts/render_book.py转换人工审阅Markdown；它们是档案排版辅助，不自动生产适合人的完整版。输入book.json中每个documents条目包含id/title/group/source_path/reader_path/source_sha256/tokens；路径由宿主实际定位，脚本不联网和摘要。Marked与PDF依赖沿当前宿主准备，不自动下载。图解正文则使用人工编写的story及可选render_visual.py，不能从原文自动切卡片代替编讲解。

book顶层还需title、edition、introduction及documents，可选short_title/output_stem；`introduction`与story的`intro`不是同一个字段。HTML-only时将格式显式设为html；图解主线可选render_visual_html.py，不为它准备PDF字体。assemble_html.py同时支持这一路径，只合并已审输入，不自动补缺失章节或来源。

HTML正文全部展开，目录可折叠，图片有就地放大与原图回退，窄屏长表保留列并滚动。本地MD链接转换为册内章节或原件定位卡，不能直跳源码。PDF输出层级书签、可点击目录、案例/来源文内链接及页脚返回目录；跨阅读器效果仍须按实际环境检查。

```text
node parse_markdown.mjs book.json /local/marked.esm.js
python render_book.py book.json --out full --format both --font /local/chinese-font.ttc --symbol-font /local/symbol-font.ttf
```

输出后至少核对：全部文稿/块是否被承接；重要条件与反例；图片/表格/代码是否完整；PDF目的地是否对应正确章节、长表分页是否读得清；网页锚点、返回、放大关闭、键盘、窄屏与无外部资源请求。PDF按专门技能实际渲染核验，不把生成成功当内容通过。当前辅助覆盖报告阅读和有限图片查看，没有实现或验证任意交互模型、演示、视频或多用户协作。

字体要覆盖实际字符；主字体缺字时显式提供符号字体，两者均缺字就停止制作。不能把数学减号变成空白后仍称数值保真。长表需检查标题与首行相连、跨页重复列名；页脚已有回目录时，避免在章末单独挤出一页空导航。

Humanizer-zh不可用时，按上述冗余、歧义、衔接与事实保全要求就地审阅，明确未调用；不以缺Skill中止独立制作。
