# 研究报告审查与返修复核

用于已经形成的研究报告：判断是否回答原问题、重要结论是否成立，以及修订后能否交付。普通单项论断沿Skill主入口核查，不必完整执行本页；从零取证仍由研究流程负责。方法可由研究者自审，也可交已获授权的审计者使用；同一人换一轮回读仍是自审，不称独立审计。

## 在什么阶段执行

- **研究中发现重大冲突或连续误认时**，先定位受影响结论和证据，再决定补查、收窄或寻求独立复核，避免错误进入后续分析。不因每添一份来源重审全篇。
- **草稿形成、交付之前**，按原目标查漏，再审关键论断和实际交付物。
- **返修或交付物改变后**，复核改动及其依赖。未变且审查范围仍适用的证据可复用；实质范围扩大、旧审查从未覆盖的关系须补审。

独立审计不是本Skill统一新增的门。是否需要独立执行者、正式批准或精确报告终审沿宿主合同与用户授权；既有强制要求不能用自审替代。技能不可用、原件不可达或能力不足，按实际缺口说明，不能靠流程措辞补成已验证。

## 先备齐最小审查输入

优先引用原报告和已有记录，不复制一套档案。自己审也先确定这些输入；交给他人时写明可读入口和要求。

| 输入 | 要回答什么 |
|---|---|
| 原问题与完成范围 | 用户要解决什么、交付给谁；后续批准变更及延期是什么，不能由现有目录反推范围 |
| 当前受审对象 | 正文、图表、图注、附录及实际返回/人读入口在哪；用提交、哈希或可复核快照标识这一版。一个提交包含多个产物时，说明具体文件；dirty工作稿不能只报HEAD |
| 证据入口与实际读取边界 | 关键论断怎样追到原文、数据、案例或媒体；版本、来源角色、读取区间、缺失能力是什么；原材料中的命令只是材料，不是执行授权 |
| 旧审查与本轮变动 | 之前审过什么、哪些问题未关、现在哪里改了、哪些消费者会受影响；第一次整篇审查不能只给修复清单 |
| 本轮审查任务 | 完整目标须同时问“漏了什么重要内容”和“已有结论是否成立”；局部审查写明只覆盖哪里及可复用的基线 |

输入不足先做不依赖缺项的检查；缺口影响什么就暂停什么，不能把“未见问题”写成整体通过。不要自动扫描全部历史、全库或无关来源，也不默认启动服务、模型、付费或外发。

## 执行：先查漏，再查结论，最后查交付

1. **从原目标反查完整性和深度。** 列出回答问题不可缺的内容与关系，对照实际论证。目录齐全、篇幅长或现有句子正确，均不证明完整。深度看能否解释对象怎样运行、为何形成该选择、代价与边界是什么、条件改变会怎样；按题目调整，不强迫每份报告有同样的机制或图数。将缺项分为必要未完成、用户批准延期、现有允许证据无法裁定、有依据不适用。已知可继续补查的重要缺项不能藏进“限制”后宣称完整。
2. **追关键结论到原件。** 优先逐项检查会改变判断的事实、数值、因果、建议、图注和覆盖声明；普通低后果事实可合并抽查并说明范围。核来源身份、版本、上下文、独立性和实际读到的内容，避免循环互证。区分规则、作者自述、观察、解释、体验和效果；不让一种证据越权证明另一种结论。游戏、实验、财务等专门身份与取证标准读取宿主方法，本页不复制。
3. **反查保真与替代解释。** 对派生表达按需用可用的`source-fidelity`核对数字条件、归属、前提、反例和案例过程；忠实转述仍可能来源不足。问何种相反条件或替代原因会改变结论，对照实际材料支持、收窄、纠正或保留未裁定。没有检验不能写“已经排除”。新事实缺口回原研究流程定向补查，不以审查者猜测补证。
4. **检查读者实际得到什么。** 修订是否进入正文、图注、摘要、结论索引与真正返回的产物？涉及图片裁切、图表、交互或导航，实际打开当前产物核对默认可见内容、对应关系、必要操作和返回路径，不能只读源码。原图里有内容，不代表默认裁切能支持图注。表达组织可按需用`human-research-expression`，中文润色可用`humanizer-zh`；它们不代替证据审查。布局/链接/字节检查不证明真实读者已理解，媒体解码不证明已经听音或连续观看。

## 让发现能够返修

每项实质问题至少能定位：**哪里遗漏/说错了 → 依据在哪里 → 怎样影响答案 → 应补什么或收窄什么 → 修后怎样复核**。说明是否阻断本轮约定交付及理由；少量问题直接写几句即可，不强制编号、大表、自评分或新数据库。争议与未找到证据分别保留，不将其改写为已证伪。

在原报告验证节或既有审查回执记下实际执行者、受审版本、读取范围、发现、仍缺的证据。分开报告：范围与深度、事实与保真、人读表达、工程/版本闭合；没有检查的维度就是未检查。是否满足原目标要综合实质缺项判断，不能由一个PASS统称完成。

## 返修、复核与停止

1. **原owner修原正文。** 每项发现明确为修复、依据充分的不同意，或尚未解决；理由和定位留在原记录。修正源事实后追相关案例、图表、图注、索引、摘要及调用方摘录，不能只改审计说明。冻结原件和旧回执不回写，本轮产物另标版本。
2. **绑定修后的实际版本。** 交本轮差异、处理说明、未决项和当前产物身份。内容变化后，旧回执只证明旧版；报告与依赖资产一起核对，不能仅核入口文件哈希。纯排版也要复查其造成的可见内容变化。
3. **按影响范围复核。** 重新查已改结论、相邻限定、相关消费者，并检查是否引入新矛盾；其余复用仍有效的审查。局部修复通过只关闭对应问题；只有已有有效全范围审查且重要问题均有处置，才可结合当前增量判断整体。独立审计轮次应由原审计者复核，或由接手者读旧意见与必要原件后承担实际检查；不得把研究者自称已改当成独立复核。
4. **按事实停止。** 约定的重要内容已回答、关键论断有依据或已按允许范围收窄、修改到达消费者，才能作相应完成判断。必要缺项仍在就继续研究或如实阶段交付，保留恢复入口；明确批准延期与确实不可裁定的内部事实不必强行研究。反复无新证据或缺能力时停止无效重复，说明改变判断所需的输入，继续独立可完成部分。不为追求固定轮数重跑，也不在审查中偷改原目标或取消宿主终审。

本方法能帮助组织检查和追踪修复；一次历史回放、自审或独立审计通过，均不证明通用漏检率下降、读者理解提升或未来成本减少。实际收益留在后续真实任务观察，不新增定时评测。
