# 证据审计

## 触发与预期结果

已有说法、材料或方案需要判断可信度时使用。交付关键结论的证据状态、推理缺口，以及可以保留或应当收窄的表述。审查整份研究时，还要判断原问题的重要内容是否遗漏。立场表达、创作或从零广泛研究不进入本流程。

## 硬边界

- 区分可验证事实、推断与价值判断；“未找到证据”不等于“已证伪”，有来源也不等于结论成立。
- 核查深度与风险和决策后果相称；医疗、法律、金融等高风险结论核对最新权威来源，并说明专业意见边界。
- 不以引用数量代替来源质量与实际覆盖，不因材料缺失编造事实或强行裁决争议。

## 方法选择

只审一项论断时按下述方法核查。审查研究报告的完整性、深度，或组织审计交接与返修复核时，读取[研究报告审查与返修复核](references/research-review.md)，先查原目标与重要遗漏，再审已有结论。项目的领域、媒体、正式验收与授权仍由宿主合同规定；本Skill不要求另开聊天、固定人数或新增审批。

优先核查会改变整体判断的主张，确认来源身份、日期、样本范围与上下文。检查是否循环引用、遗漏假设、偷换概念、混淆相关和因果，或忽略合理替代解释。

依据证据将结论判为可支持、需收窄、有争议、证据不足或错误，附可定位的材料与理由。多项材料适合表格，少量结论可直接说明；不强制分栏、标签或固定输出顺序。

## 完成标准

关键主张能追溯证据或明确缺口；用户能判断哪些内容可信、怎样修正、补什么证据才可能改变结论。整份研究的审查还须交代重要遗漏与实际复核版本。范围有限的审计不声称覆盖未检查的材料，局部返修通过不自动成为整体完成。
