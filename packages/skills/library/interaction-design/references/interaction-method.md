# 界面交互：状态连续、操作反馈与动效取舍

网页、App、小程序与游戏UI按需共用的方法。视觉方向沿frontend-design，游戏表现沿GamePresentation；本文只补交互决策，不拥有业务规则、资源、项目状态或验收权。普通静态样式修改不必加载，已有宿主规范有效时优先复用。

## 先确定动作与状态，再选效果

先回答这次要改善的是定位、理解、控制还是注意力，而不是先挑动画。沿宿主现有工作单记录触发输入、真实状态变化、即时反馈、完成/取消和保持不变的内容即可，不另造表单。加载/提交与成功是不同状态；动画结束不能代替请求完成或规则结算。

每次优先选一处有明确用途的变化；以下是选择依据，不是必须集齐的效果清单：

| 需求 | 可选做法 | 保留条件与替代 |
|---|---|---|
| 同内容需兼顾浏览与查找 | 大图/网格/清单的语义密度切换 | 同一稳定ID、选中项、焦点和阅读锚点保留；按钮/菜单可直达。双指手势只在确有需求且不阻断浏览器缩放时附加 |
| 布局变化后不知对象去了哪里 | 按对象身份从旧位置到新位置的短过渡 | 先保证最终布局、顺序、焦点正确；直线/少量移动通常足够，不强制弧线、逐项长延迟。快速再次切换立即服从最新状态 |
| 编辑摆放难以精确 | 靠近参考线吸附，同时显示吸附依据 | 阈值使用同一坐标系与缩放尺度，边界不反复跳；保留取消/撤销及键盘、按钮或数值替代。吸附不能让非法目标变合法，游戏落点仍由规则拥有 |
| 用户需集中比较一个对象 | 选中项原位强调、非关键装饰轻度弱化 | 持续语义靠边框、文字或状态标记；仍需比较的数值、敌人意图和可行动对象保持可读，不默认模糊或降低整层透明度；可取消和切换 |
| 长文/步骤需要定位 | 可逆的阅读/步骤进度反馈 | 进度跟实际位置，不伪造完成；原生滚动和内容访问保持。展示动画不能劫持导航 |
| 浮层覆盖复杂图片 | 稳定底板、描边或经验证的局部主题 | 单次平均亮度、黑白反色或差值混合均不能保证全部背景与过渡帧的对比；检查实际文字/控件状态与最差区域 |

速度模糊、拉伸头图、强视差和大片回弹是有成本的风格选项。只有服务当前目标且目标设备实测合适时使用；高频阅读、战术信息或精确输入优先清楚和稳定。不要把更多通道、统一100ms或固定弹性参数变成所有产品的要求。

## 连续操作与取消

- 显示以最新业务/游戏状态为准。新选择、再次切换、返回、隐藏或销毁时取消/替换旧表现；旧回调不得恢复过期状态、重复提交、重复结算或抢焦点。
- 区分外层布局/命中区和内层视觉。装饰缩放、阴影和拖尾不应移动操作目标或拦截输入；真正的布局/拖拽变化也要核对视觉位置与命中位置一致，不把“视觉层独立”当万能实现。
- 拖拽处理松手、取消、失去捕获、越界和窗口变化；取消回到本次开始的有效状态并清掉辅助线。精细键盘/数值输入应能退出或绕过磁吸，避免每次微调又吸回原位。仅在确需手势的局部使用触控限制，保留页面原生滚动/缩放。键盘支持与无需拖拽的单指替代分别核验。
- 动画时长、错峰、位移、模糊与并发按当前设备和任务选择。先改一处，不能只看录屏顺滑就推断操作更快；检查短时间连续操作和主线程/帧时间，性能未测保持未知。

## 减少运动仍能完成任务

网页响应系统prefers-reduced-motion并提供必要的宿主选择；Godot/其他游戏沿已有简化动态或无障碍设置。关闭非必要位移/缩放/视差后，选中、成功、失败、进度和吸附依据仍由稳定标记表达。初始偏好和运行中变化都应生效；不要等动画回调才解锁核心操作。

## 最小验证与收尾

沿宿主已有QA做相同状态的“无增强/有增强/减少运动”对照，只覆盖本次功能实际支持的输入与目标尺寸。至少核对正常操作、快速反向/重复、取消/返回、焦点/选中保留，以及效果结束或场景退出后的清理；失败/禁用等存在时一并覆盖。截图验证外观，真实交互验证状态与命中，必要采样验证性能，用户判断体验，四者不互相冒充。

难观察、难调参或难复现时，可组合已提供的feedback-loop；已有Inspector、日志或固定场景足够就复用，不因本文新建平台或依赖某个工作区。真实问题、验证及采用回原宿主；外部灵感、实验与净收益留宿主研究记录，本文不保存私人候选或固定游戏参数。

参考边界：[W3C交互动画](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)为AAA条目，[拖拽替代](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)为AA条目，两者不代表一次小样已通过完整WCAG；[MDN减少运动](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)、[pointercancel](https://developer.mozilla.org/en-US/docs/Web/API/Element/pointercancel_event)和[动画取消](https://developer.mozilla.org/en-US/docs/Web/API/Animation/cancel)用于具体实现，仍核对目标平台。
