# 交互配方：按任务选控件、状态与动作

需要具体选型、实现或复核时只读命中主题。先复用宿主组件和已确定规格；[交互方法](interaction-method.md)拥有连续操作、取消恢复、输入替代和减少运动的共用约束。这里是可选择的做法，不是整套必跑清单；图片/录屏中的观感不证明真实操作或净收益。

| 当前问题 | 读取主题 | 可观察的改善 |
|---|---|---|
| 点了以后不知道是否生效、失败或仍在处理 | 反馈状态 | 能判断实际进度、结果和恢复方式 |
| 选项多、结果有层级，或输入容易丢失 | 选择与输入 | 少重复输入、误选和旧结果覆盖 |
| 入口难找，或弹层打断了原任务 | 导航与弹层 | 少查找往返，保持当前任务与焦点 |
| 展开、重排后不知道对象去了哪里 | 对象转场 | 变化前后认得同一对象，能回到原位置 |
| 滚动与拖动争抢、精细操作难、中途不能接住 | 手势与控制 | 动作服从意图，能取消和准确调整 |
| 查看详情只是为了做一个小操作 | 就地操作 | 少进出页面，且操作范围清楚 |
| 想比较一个阈值/范围会怎样 | 可操作图表 | 输入、计算与读数对齐，可以比较并恢复 |
| 变化难理解，或运动喧宾夺主 | 动效表达 | 关系更清楚，主任务和可操作位置稳定 |

## 反馈状态

把输入已接收、处理中、确认成功与失败恢复分开。点击反馈可以立即出现；复制成功、保存完成、删除完成等结果须等待对应能力确认。未知进度使用不确定状态，只有真实可计算的过程才显示百分比；步骤条区分完成、进行中、跳过和失败。

- **原位过程**：保存/上传按钮内显示过程，适合用户要守着这一动作等待时；仍要保留说明和可恢复入口。长过程可让用户离开并返回，不要求盯着动画。
- **停止与取消**：立即响应停止意图，显示“正在停止”；后端确认才显示“已停止”。请求未送达、停止失败或仍有已执行副作用时明确说明；停止不等于删除，也不自动撤回已发送内容。
- **部分完成**：显示已完成与未完成范围，提供查看失败项/按步重试，避免全绿成功掩盖遗漏。重试沿原任务幂等规则，不让按钮动画重复提交。
- **确认成本**：高代价动作可选择清楚的确认摘要；长按/滑动仅在实际误触风险值得时使用，并保留可达替代。高频普通操作不额外加等待仪式；视觉确认不能代替权限或业务校验。

## 选择与输入

先定义选择结果：单值/多值、是否可搜索/新建、平面/层级/范围，再选控件。少量稳定选项用原生select、单选或复选即可；大量且可检索的集合再考虑combobox。命令动作与选择一个数据值分开，不能因外观相似混用行为。

- **异步候选**：区分尚未查询、加载、空结果和失败；用取消请求或请求序号阻止旧结果覆盖新查询。已选项以稳定ID保留，不随候选刷新丢失。
- **多选/新建**：说明是否即时生效或集中应用、重复项如何处理；标签删除后焦点有去处，必要时可撤销。新建项按宿主做空白归一、去重和权限检查，不把“没有找到”直接变成创建授权。
- **层级**：明确选父是否包含后代、半选是什么意思、返回父项还是叶子；这些是数据语义，不由勾选动画决定。大集合按当前需要过滤/分段，不一次渲染全部选项。
- **范围/日期**：两个端点定义单位、步长、上下限和交叉规则，保留精确输入；视觉位置变化不打乱键盘焦点顺序。单日/简单日期优先评估原生输入，复杂范围才定制，显示格式与存储语义分开。
- **中文编辑**：考虑IME组合期间的回车/筛选、光标与候选位置；格式化数字/日期时保持编辑光标，不每次替换整段。真实label持续可识别，placeholder或浮动动画不作唯一说明。

ARIA combobox主要定义单选，多选标签需自己的完整操作语义；listbox option不支持内部独立按钮/链接。按真实行为选择模式和组件，再验证目标输入，不能仅加role就当可访问性完成。

## 导航与弹层

集合摘要、常用项固定、同级面包屑和渐进展开分别减少空间、重复查找与层级往返。选一种符合实际规模的入口；少量页面不为风格增加Mega Menu，多级操作不全藏进hover。常驻日期/底栏保留锚点和主要动作，不能遮住内容、软键盘或安全区。

| 要做什么 | 合适起点 | 要明确的行为 |
|---|---|---|
| 去另一页面或分组 | 普通链接、disclosure导航 | 当前项、返回位置、键盘/触屏展开；普通站点导航不必套menu语义 |
| 执行一组动作 | Menu / Menu Button | 启动与退出、焦点移动、动作确认；不把选中值伪装成菜单命令 |
| 必须先做决定/处理一个任务 | Modal Dialog | 可访问名称、背景不可操作、焦点在内、关闭与返回策略；关键未保存输入另处理 |
| 一边参考背景一边编辑 | 非模态面板、Drawer/Sheet | 背景是否仍可用、焦点与关闭；侧滑外观不自动等于modal |
| 短说明且无需内部操作 | Tooltip | hover和焦点均可获得，能关闭；需要链接/输入则换可交互容器 |
| 同一任务切视图 | Tabs或明确切换器 | 保留上下文和选中，不能混同离开页面的导航 |

状态点/数量应来自真实状态，并有文字或可访问名称；0、未知和无权限分开。底部动作区只保留当前需要的操作，不机械复制桌面导航。选型后沿共用方法检查返回焦点和不中断输入。

- **原生能力选型**：简单、独立的网页窗口可先评估原生`dialog`、Popover及声明式开关；Popover本身不提供模态隔离或完整菜单操作。按目标浏览器分别核对`showModal`、`popover`、`commandfor`、`closedby`等实际使用的特性与回退，元素存在不代表所有扩展都支持。已有组件更符合任务时继续复用，业务保存和撤销仍由宿主处理。
- **外点关闭与焦点**：需要外点收起可评估`popover="auto"`，需要边看背景边保持面板则评估`manual`或已有面板；manual的Esc与焦点恢复由宿主明确处理。分别核对外点、Esc和关闭按钮：关闭范围是否正确，焦点是否回到有效入口，草稿是否保留；一种关闭路径通过不能代替其余路径。
- **跨模态容器**：浮层处于顶层不等于可操作，先核对活动模态框的输入隔离与DOM归属。将面板迁入/迁出容器可能使原生Popover收起；以相同任务检查展开状态、草稿、焦点和输入归属是否连续，不能只加z-index或Popover属性就判为修复。迁移需额外适配且没有净收益时保留宿主原实现。

## 对象转场

卡片展开和共享元素过渡适合同一对象从摘要到详情；堆叠/托盘适合集合摘要，翻面适合同一对象的补充面。需要同时比较的数值不要藏到背面。用稳定对象ID维持身份，布局/顺序和实际点击区先正确，再增加轨迹。

图片/容器可以过渡，正文应在目标布局重新排版，避免整卡缩放造成文字拉伸。关闭后按当前真实列表恢复对象/邻近位置；对象删除或排序变化时不依赖旧数组下标。减少运动时以明确标题、选中和返回关系维持理解，不强迫长转场。

## 手势与控制

横向拖动嵌在纵向阅读时，按主方向和实际意图仲裁；锁轴阈值随控件、设备和缩放验证，不把演示中的像素数当通用标准。局部touch-action在手势开始前设置；浏览器接管滚动会产生pointercancel，不能靠中途改样式追回手势。

指针捕获可让拖动越界后继续接收事件，但会改变enter/leave等事件表现。需要“移出取消”时核对坐标/目标区及捕获状态，不能只依赖pointerleave。松手、取消、失去捕获和失焦都要有明确结果。

可接住的运动对象从**当前显示位置**续拖/反向，旧动画与完成回调退出；不是从旧目标点重启。吸附显示参考依据、采用一致坐标系，精细输入能绕过磁吸；弹性越界区分预览与合法最终值。速度变形、回弹不改变真实值和业务落点。

拖动之外提供按钮/数值等非拖动方式；单指替代和键盘替代分别检查。长按录音还需真实权限、录制、取消、失焦与保存状态，波形动画不能证明已录到声音。

## 就地操作

列表/卡片内的收藏、标记、数量调整等小操作，可减少仅为操作一次而进入详情的往返。外层打开详情与内部动作要有清楚的命中、焦点和事件边界，避免整卡链接嵌套按钮；复杂编辑或关键确认仍可进入详情。

固定动作区、局部更新和“飞入目标”可表达对象去了哪里，但真实增删/保存仍沿宿主确认与恢复规则。保留同项身份、编辑值与邻近阅读位置，不因一条更新重建整列表。只有变更字段动起来时，金额、日期等整体含义仍须清楚。

## 可操作图表

目标线/范围滑块适合开发、分析或用户本来就需要试探条件的任务。明确原值、临时预览、确认值和一键恢复；屏幕位置到数据的反算定义尺度、单位、步长和clamp，并保留精确输入。动画插值只表达过程，不能冒充实时业务数据。

同一对象跨图表/排序变化保留稳定身份；颜色外还有标签或数值，气泡面积与半径的编码分开。连动计算应消费同一输入与模型，只有读数变化而计算未更新不算生效。

是否把预览放到玩家界面由游戏目标决定：公开结算/最优解可能帮助分析，也可能损害悬念、探索和行动节奏。开发工具可观察性不能自动变成玩家应知信息；沿宿主规则与实际体验判断，不泄露角色未知或隐藏状态。

## 动效表达

用轨迹说明来源/去向，用连续重排说明关系，用短反馈说明命中；先选要表达的关系，再定时间轴。邻近元素回弹可表达接触感，但不能暗示未发生的选择、碰撞或规则结果。装饰磁吸不移动真实确认目标，视差/模糊不遮比较信息。

速度、时长、错峰与弹性是目标任务的参数，不能把更多运动当质量下限。高频操作和长时间阅读优先清楚稳定；即时反馈不要求每个元素都动。布局变化优先避免整块文字缩放，必要时分别处理容器、内容与焦点。

简单状态可用宿主原生动画/CSS/WAAPI；多对象串联或SVG等确有缺口时再选对应时间轴工具。Web的View Transition/GSAP与Godot原生动画分别按宿主实现，不因本配方新增运行库。清理动画之外还要清理手动监听；减少运动的功能等价与实际性能沿共用方法核验。

## 实现依据与证据边界

这些是可迁移的任务配方，不是某视频成品、品牌资产、固定审美或通用最佳参数。实际采用和省工回到宿主记录；完整原文/案例由宿主研究或知识库维护，本文件无需私人目录才能使用。

- 控件语义：[Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)、[Listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)、[多滑块](https://www.w3.org/WAI/ARIA/apg/patterns/slider-multithumb/)、[标签](https://www.w3.org/WAI/tutorials/forms/labels/)。
- 导航/弹层：[Disclosure导航](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/)、[Menu Button](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/)、[Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)。[Tooltip模式](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)当前仍标明work in progress，示例不代替目标环境验证。
- 原生弹层：[Popover](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API)、[声明式命令](https://developer.mozilla.org/en-US/docs/Web/API/Invoker_Commands_API)、[dialog与inert隔离](https://html.spec.whatwg.org/multipage/interaction.html#inert-subtrees)。这些描述平台机制，不能代替宿主行为与目标浏览器验证。
- Web机制：[Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)、[touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)、[Animation.cancel](https://developer.mozilla.org/en-US/docs/Web/API/Animation/cancel)、[View Transition](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)。动画取消的finished Promise可能拒绝，旧流程需正确退出，不能把取消当成功回调。
- 图表与反例：[D3尺度反算](https://d3js.org/d3-scale/linear)是可选实现参考，不要求安装D3；[GMTK的Balatro信息预览案例](https://www.youtube.com/watch?v=zk3S3o1qOHo)用于说明信息披露取舍，属于作者分析，不是通用玩家实验结论。
