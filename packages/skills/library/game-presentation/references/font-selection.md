# 网页与游戏的字体选型

在新增或替换中文字体、标题风格不合适、缺字、数字难辨或交付需嵌入字体时使用；已有字体满足需求则复用，不为普通改色或一次文案修改重新选字。网页视觉方向仍由frontend-design拥有，游戏效果与采用仍由宿主拥有；读取本文不要求加载整套游戏工作流。

## 发现与核查

可从[猫啃网](https://www.maoken.com/)按中文、风格和预览发现少量候选，再追到作者官网或源仓的具体版本、原许可和发布文件。站内同时有免费、付费和[存疑字体](https://www.maoken.com/zhengyi)；搜索标题、标签、站内证书和在线预览都不单独构成实际文件的发布许可。站方也说明[不保证镜像始终最新](https://www.maoken.com/update)。不整站下载、默认安装客户端、上传私有画面识字或为此启动服务；普通网页已足够，未核实官方API/MCP时不猜接口。

先明确用途：正文/HUD重可读和覆盖；短标题可强调个性；像素字体要匹配实际像素尺寸与缩放。用宿主真实文本比较2–3项，至少含中文、英文、数字、标点、长提示及项目特有字；不要把日文字库“有汉字”当简体覆盖，也不把星级当字符表。已有已审核Noto/思源等可作基线，不自动替换。

许可分别核对静态成图、网页字体文件分发、游戏/App嵌入、修改/子集化与再分发。按文件保留版权声明、许可原文、作者来源、版本/tag或完整commit、下载时间和SHA-256。OFL通常允许随软件商业分发，但须按[正式条款](https://openfontlicense.org/open-font-license-official-text/)保留声明和许可，不得单卖字体；转换/子集化涉及修改版，检查Reserved Font Name及该作者的额外许可。OFL字体不因此要求整款游戏或网页代码开源。仅“作者声明免费”者查明确使用范围，不能默认继承OFL。未知权利的候选停在候选，不能填发布允许。

## 接入与验证

- 网页：沿宿主静态资源目录与许可记录保存；只有确需时转换WOFF2/子集化，留原版及加工命令/输出哈希。真实浏览器确认指定字体加载、断网/失败回退、长文换行与布局变化；动态中文输入不能只截取当前页面文案。系统可用不等于访问者可用，避免把第三方字体CDN变成必需依赖。
- 游戏：沿GamePresentation项目资源工作台和原引擎导入合同保存；进入PrototypeAssets共享精选须遵循其来源准入，猫啃不是自动下载白名单。实际目标窗口核对缺字、数字区分、字重、描边、基线、缩放/过滤；动态名字和多语言须有覆盖或明确fallback。检查实际导出包字体与许可，不能只靠编辑器中的系统字体。
- 技术加载、许可、视觉采用、真实使用效果分别记录。无当前使用任务时只登记发现入口，不预装一批字体或声称已验证渲染。来源说明不是每次重新选字的强制清单，验证按改动风险裁剪。
