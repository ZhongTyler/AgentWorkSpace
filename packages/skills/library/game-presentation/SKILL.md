# 游戏表现

先读宿主的目标、资源规格与当前实际效果。若已安装 game-presentation 包，从其 README/workflow.md 加载本轮阶段；也可使用宿主已有等价流程，不假定固定目录或另一个包存在。

用户选择本地生图时，按需读game-presentation包的local-image-workflow.md和Tools包的integrations/local-image/README.md。FLUX通用、Anima离线动漫、Z-Image中文概念一次选一条；通过Tools有限JSON入口生成或只加工已有PNG，按缺口调用抠图、明确遮罩合成或放大。先少量代表图，在真实尺寸和深浅底审查源图/加工版；adapter只生成未采用审图工作台，制作人确认后才走原交付。缺工具不隐式切云端。

先核对本机安装、物理/提交与显存，单重模型执行；最低预检不是稳定长批承诺，不自动调整页面文件或关闭其他任务。原请求恢复同批需验输入/输出哈希，失败或漂移不覆盖、不抢owner。CPP、SDXL/IP未过本轮质量增量门，SANA因提交不足未评效果，均不当作已接入；详见Tools的docs/local-image-validation.md。Anima仅沿经核对的离线图片用途，不能继承商业在线模型功能许可；未采用运行文件的删除仍须宿主授权和精确保全计划。

缺少工作流包时仍可完成本轮表现任务：固定用途、目标尺寸和可感知信息；先制作或选择少量样张，在真实尺寸与同一场景对照；核对来源与分发权后，复制采用资源及必要许可到用户项目，使用其实际引擎接入与验证方式。只有生成、引擎或交付工具本身不可用时，明确止于相应准备结果，不伪造图片、显示或构建。

位图、角色小尺寸、地图棋子与头像分别验证，不能以立绘缩小替代用途通过。UI 图片负责装饰，动态文字、数值和交互由实际控件拥有。对比真实运行与样张的组成、层级和信息可读性，不只查文件存在或可点击。

源、加工版、采用版与运行副本分开。更新前预览变更，保留恢复点；用户修改或未知所有权文件不得静默覆盖。回退先撤消费者引用再撤资源，恢复顺序相反。真实包需保留许可、排除私人提示和调试桥，断开来源后仍运行。技术可用、分发权、风格选择和用户效果接受分别报告；不拥有玩法规则或产品决定。GameAnalysisDecision 和 PrototypeAssets 均可选。
