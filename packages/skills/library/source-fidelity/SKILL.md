# 来源保真

目标是让读者从派生正文中得到来源的必要知识及其成立边界，而不是得到同话题的一篇新文章。沿宿主已有任务、材料和审核合同工作；本方法不创建新流水线、审批、固定人数或复核轮次。

## 从论证反查表达

先读完整相关来源及派生正文，定位作者要解决的问题、如何推到结论、用什么证据，以及哪些情形不成立。已有可靠审核且输入未变的部分沿原范围复用；发生版本变化时，只能复用仍有证据覆盖的范围。

双向核对：来源的必要知识是否得到承接；派生正文每项事实、因果、定义、分类及建议是否有依据。标题和表格同样可能新增主张。“同一主题都提到了”不代表关系正确；完整阅读也不意味着逐句抄录。

把以下检查用于实际承担论证的内容，不要求为每句话建立一张新表：

- **无源新增**：追问是谁提出该分类、步骤、因果或处方。整理用标题可以改变结构；把整理者的组织方法写成作者提出的理论，则改变了归属。必要综合放在允许综合的产物中并标清来源与推导，不倒灌进原作者声音。
- **数字语境**：连同数值核对单位、测量对象、成立条件和比较关系。帧数依赖帧率；距离、速度、耗时属于不同量；只在长间距成立的比较不能覆盖全部间距。保留这些条件比抄全所有数字更重要。
- **删除测试**：删掉这条前提、反例、失败路径或“不一定”，读者会不会改变适用判断或结论强度？会改变就必须保留。“一般”变“必须”、“作者猜测”变“事实证明”，即使句子更短也不等效。
- **案例链**：保存理解论点所需的情境、机制/动作、结果及它为何支持或限制结论。只有作品名或“某游戏做得很好”不能代替原案例；无论证作用的场景装饰可以省略。

## 角色、日期与媒体

分别识别原作者、译者、转载者、编者和整理者；引用他人的意见不自动变成本文作者结论。日期也分采集、本地发表/译制、原文首发与案例发生时点。只填来源支持的层级，来源内时点矛盾应披露，不能靠常识补出唯一时间线。

图表、公式、流程和视频若承担必要知识，要实际读取并承接其含义；正文已完整承接或只是装饰时，保留具体省略依据。小字不可读、媒体受限或图文冲突时，明确受影响的知识范围；看过静态抽样不等于看完整动态材料。

忠实转述不等于外部事实已被证明。保留作者当时的说法和不确定性；只有任务需要且授权允许时另做外部验真，结果与来源归属分开。

## 给出能返修的问题

每项真实缺陷给出来源落点、派生正文落点、改变了什么含义及应保留的必要信息。同一篇的问题集中交给原内容owner；修复后检查受影响命题、相邻限定及实际下游消费者。内容正确的部分可以不改；缺材料的部分保留限制，不能为交付“全部通过”猜答案。

完成结论区分正文保真、元数据身份、媒体覆盖和外部事实。只报告实际核对范围；格式/版本检查不能替代含义判断，也不能用新增字段或本文方法保证漏检率。
