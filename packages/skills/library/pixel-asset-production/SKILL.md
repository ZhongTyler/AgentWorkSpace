# 像素资产制作

先沿宿主说明用途、目标尺寸、方向、动作、风格与资源权利，读[生产路线](references/production.md)选择当前需要的分支。保留原图、层与时序，按真实引擎核验；不能把上传参考图、骨骼重定向或文件生成当成还原和美术采用。

本方法不要求Tools或GamePresentation。按实际已配置能力选择外部编辑器、现有生图工具、程序化候选或手工逐帧；缺少转换器时交付可复用规格/原件并说明未执行项，不自动安装、调用模型或修改正式项目。
