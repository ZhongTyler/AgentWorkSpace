# 按输入选择生产路线

- 只有文字/风格目标：先做用途规格与单张首样，核实际目标尺寸中的轮廓、色阶和身份，再扩内容；不先铺满动作表。
- 已有参考图：保全原图，区分近似结构重建与原像素保真。生成器不支持原像素保真时明确说明；不能只把参考图存进任务就说完成绑定。
- 已有透明图层：保留同尺寸画布、叠放顺序、pivot与原帧时长；可用现有编辑器或已配置的有限合成器做小幅平移/旋转。它不自动补被遮挡内容，不等于自动骨骼绑定。
- 已有骨骼/GLB：先核引擎、格式、动作和许可。固定样本能导出不代表任意角色重定向；动作/视角/取景与输入原点分别记录。
- 已有逐帧图集：检查裁切、透明边、方向命名、锚点、每帧持续时间、循环/一次结束及末帧保持；不把整张图集当单体送入法线生成。

单帧可选最近邻等比缩放与透明补边，网格修复或重新限色只在确有需要且获准时进行。法线先比较平面、轮廓和默认版本，不把颜色纹理都解释成凸起。动画法线需要逐帧和连续受光验证，缺少支持时保留原色路线。

在目标引擎验证目标尺寸可读性、锚点/足底、动作切换、移动边界和真实输入。交付原件、帧序/时长、采用规格、许可与恢复方式；先在实验副本验证，再沿宿主授权接入。工具/source锁、哈希、引擎播放和实际美术/游戏采用分别记录，未知组合不沿用其他样本的通过状态。
