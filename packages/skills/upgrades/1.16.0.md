# Skills 1.16.0

`game-decision-support` now routes genuine knowledge gaps through Knowledge Query: BM25 first, bounded hybrid for actual recall gaps, and original Query fallback. Candidates still require real source reading. Existing project decisions, ingestion approval and game playtests remain authoritative.

Upgrade the package with the workspace installer, then explicitly upgrade the selected Skill using the Skills tool. Package installation does not activate a client Skill. Preserve modified recipient Skills and review the reported conflict; do not overwrite them. Roll back the package transaction and the selected-Skill transaction separately. Other Skill bodies are unchanged; catalog version/hash metadata advances with this release.
