# Skills 1.17.0

Upgrade from library 1.16.0. Adds optional interaction-design with its complete relative method reference. Select the new Skill explicitly; upgrading the package never installs a client Skill implicitly. Existing selected game-presentation users upgrade their selected Skill separately after the package upgrade.

The optional manual frontend hook is documented in integrations/frontend-design.md. It does not distribute or overwrite an external frontend Skill: preserve its body, license and local changes. Package rollback, selected-Skill rollback and the manual hook have separate ownership. Private reports, experiments, host paths and frontend backups are excluded. Engineering checks do not establish long-term trigger rates or user experience gains. Existing Query routing is unchanged from 1.16.0.
