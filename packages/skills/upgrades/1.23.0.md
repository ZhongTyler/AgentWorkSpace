# Skills 1.23.0

直接前一版 Skills 为 1.22.0（工作区发布版 1.22.1 沿用该方法库）。更新 workflow-redesign、reference-deconstruction、game-presentation 三项正文；其余 Skill 的方法字节不变。目录仍为 19 项，不捆绑或启用外部 frontend-design / prototype。

先升级工作区 package，再预览并应用已选 Skill 的 upgrade；CodeBuddy 显式选择 --platform codebuddy。full meta 内置的同名方法由 workspace 事务维护，单独选择的安装由自己的事务维护；先检查实际所有权和差异，遇到用户修改报告冲突，不强制覆盖。兼容模式保留宿主根规则。无 meta 可使用固定版本公开方法或宿主等价流程。

恢复先撤销选定 Skill 的升级事务，再撤销工作区包升级。回退保留用户资料与未选择的 Skill，后续冲突仍拒绝覆盖；外部 Skill 的手工接线独立撤销，只撤自己的片段。可达和安装验证不证明长期触发率、质量提升或净节时。
