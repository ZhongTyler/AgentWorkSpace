# Skills 1.3.1 → 1.8.0

The portable game-decision-support entry now routes game design/development evidence gaps to optional Research and REA, alongside Knowledge and GameAnalysisDecision. Other selected skills retain their content. This library version follows the distribution release; earlier distributions through 1.7.0 shipped library version 1.3.1.

Upgrade the workspace package first, then preview and explicitly apply the separate selected-skill upgrade with scripts/skills.py. Only previously installed skills are upgraded; local edits that conflict are preserved and reported. Keep both transaction IDs. Roll back the selected-skill transaction before the workspace-package transaction. Neither action installs or reverts external REA runtime, MCP registration, client skills or account settings. Tools remain optional; missing providers do not block ordinary source/material research.
