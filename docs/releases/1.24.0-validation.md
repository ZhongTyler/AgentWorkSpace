# 1.24.0 validation and limits

Date: 2026-10-20. This release changes only meta, Skills, GamePresentation and Travel from 1.23.0. The other eight component file inventories remain unchanged. Skills has 21 selectable methods; Travel carries its public workflow 0.5.0.

## Source, licenses and public scope

The two Anthropic methods are generated from the reviewed Tools-owned `anthropics/knowledge-work-plugins` revision `a266ab8c3c754a3ccf7a634044fc1595fc06e50e`. Each selected directory preserves Apache-2.0, the original Skill bytes and hashes, complete connector categories and provenance. Portable adaptations remove the unsupported Claude `argument-hint`, make the connector reference local, attach recipient-local host guidance, and preserve normal implicit selection. No original business body is rewritten. The portable adapter distinguishes measured behavior, proposals and unknowns and preserves host authority over external actions. Meta, Tools, Figma and other Skills are optional.

The source remains Tools; shared-skills holds a generated publication input rather than another maintained original. Private interface experiments, page copies, account state, client installation receipts and trial tool engines are excluded. UI UX Pro Max and Impeccable remain separate candidates, not new formal capabilities in this release.

Travel exports only its explicit 131-file public whitelist plus the release marker from the committed workflow. Real trips, preference profiles, bookings, source photographs, credentials, private services and archive siblings are outside the payload. The optional acceptance helper remains tooling only: the requested independent third trial was cancelled and was not run or certified. Existing trips are not silently migrated or redesigned.

## Verification

All 120 discovered distribution cases have passing receipts, with no skips: valid completed modules from the first run were retained and affected modules were rerun on unchanged sealed inputs. The first modular run encountered Win32 long-path errors under an overly deep fixture root; only its owned process tree was stopped, and affected or unfinished modules were rerun under a shorter task-owned temporary root. The helper-only test_publication.py contains no unittest cases; its standalone publication contracts passed separately for all four actual sources. Initial failures and recovery logs remain preserved. Travel source regression passed 108 cases, with its default browser case deferred to the separately enabled 10-case real Edge frontend run; that run passed without skips. Three changed/new Skill frontmatters passed the unmodified official validator using an existing isolated validation dependency. New recipient cases verify original-byte reconstruction, exact licenses, independent Codex/CodeBuddy selection, custom-file rollback refusal, real 1.23.0 full/compatible upgrades, separate selected-client upgrades and reverse recovery with host rules, private-trip canaries and external frontend files preserved. The other eight component file maps and all sealed payload bytes remained unchanged throughout the checks. Structural and synthetic checks do not establish automatic Skill invocation, human design acceptance, full semantic correctness or long-term benefit. Remote identity, anonymous assets and fresh recipient checks are performed after the verified result commit and retained separately; this document does not pre-certify those network actions.
