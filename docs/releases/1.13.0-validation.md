The empty template intentionally does not claim decision reception complete, asset delivery authorized, engine initialization, real playtest acceptance or production readiness. The creator only copies a reviewed baseline into a new user-owned directory. Selecting template updates for an existing project still requires reviewing its facts, decisions, customizations and recovery plan.

These checks cover source/export, creation, installation, file ownership and recovery. They do not establish game quality, Godot execution on every platform, actual prototype migration, long-term development benefit or approval of a user's project. No native Godot engine was created or run for this release.

Package upgrades/rollback manage the library, not external project copies, tool runtimes, client settings or accounts. Published tags remain immutable. After scoped commits and direct-parent closure, publication verifies remote main/tag, anonymous release-asset checksums, a fresh public clone, full inventory and fresh standalone installation/creation. Upload and clone receipts are retained outside the distribution; this document does not pre-certify them. See [upgrade and recovery](../../upgrades/1.13.0.md).
