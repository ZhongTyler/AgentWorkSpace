# 1.17.0 release verification

The portable Skills library now contains 18 selectable methods. interaction-design owns its full relative method reference; frontend integration is an optional manual hook preserving the recipient's third-party Skill and license. GamePresentation invokes that same method selectively, without a required Skills dependency or a copy of the full method. The already published 1.16.0 retrieval lifecycle and Query routing are unchanged.

19 distribution tests passed: two interaction release checks, one bilingual README check, one atomic publication recovery check and 15 installer regressions. Tests cover actual published 1.16.0 full/compatible upgrades, both Codex and CodeBuddy selected-Skill upgrades and installation, complete relative references, edited-file rollback refusal, reverse recovery and preserved private/host/frontend canaries. Package installation alone does not enable the new Skill.

Both source export contracts passed with clean committed source markers: 56 Skills files and 27 GamePresentation files including provenance. The complete catalog verifies. Only these two component inventories change; the other ten components retain exact file inventories. Root and package README, optional frontend integration instructions and package/selected-Skill upgrade guides were updated at their respective owning sources.

Private reports, experimental copies, host frontend originals, backups, user paths and conversation links are outside the explicit publication whitelist. Existing source-level browser documentation links were repaired separately; the public Tools package already uses portable references and is unchanged.

These checks establish engineering and delivery boundaries, not long-term trigger rate, user experience, Godot project adoption or time savings. Remote tag, anonymous release-asset download and fresh public clone/install are verified after the result commit; this committed document does not pre-certify those network actions. Package recovery and manual-hook ownership are documented in [the upgrade guide](../../upgrades/1.17.0.md).
