Validation results are recorded after execution below. Engineering checks do not establish knowledge accuracy, real Play, adoption benefits or long-term time savings. Relevant real tasks and milestones remain the observation point.

They now use immutable published 1.12.0 bundles and the actual historical chain. Production installation, upgrade, conflict and rollback rules are unchanged. Reusing unaffected valid results with these recovery results gives passing evidence for all 74 unique tests; the original full run is not described as green.

Separately, actual 1.12.0 → 1.12.1 installation in two temporary recipient fixtures verified clean upgrade/rollback and conflicting-meta refusal followed by recovery upgrade/rollback. Four byte canaries per fixture cover host authority, a private save, private notes and external runtime configuration. Catalog verification and format/scope checks passed. Release packaging uses canonical committed Git blobs and verifies every ZIP entry and catalog hash, avoiding working-tree newline conversions. Remote delivery and anonymous download are checked after publication in the release receipt rather than pre-certified by these local tests.
